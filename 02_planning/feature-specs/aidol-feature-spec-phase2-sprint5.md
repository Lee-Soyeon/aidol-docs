## 개요

Phase 2 Sprint 5는 **육성 시스템**을 도입하여 멤버의 성장을 수치화하고, 포토카드 생성을 통한 스탯 상승 루프를 구축합니다.
핵심 콘텐츠인 포토카드 드로우를 통해 무료 → 유료 전환율을 측정하며, 확정/랜덤 보상 모드로 다양한 유저 성향을 수용합니다.

## 1. 스탯 체계

### 1-1. 6대 스탯

| 스탯 | Max | 상태 |
|------|-----|------|
| 보컬 | 200 | Active |
| 댄스 | 200 | Locked (Phase 3) |
| 랩 | 200 | Locked (Phase 3) |
| 비주얼 | 200 | Active |
| 매력 | 200 | Active |
| 체력 | 200 | Active |

- Phase 2 실질 max = **800** (Active 4개 x 200)

### 1-2. 등급 체계 (F ~ A)

| 등급 | Range | 타이틀 | 설계 근거 |
|------|-------|--------|----------|
| F | 0 ~ 59 | 연습생 | 무료 3회로 F 후반 도달. 빠른 초기 성취감 |
| D | 60 ~ 149 | 신인 | 첫 과금의 성취 지점 |
| C | 150 ~ 299 | 루키 | 차트/대결 해금으로 동기부여 |
| B | 300 ~ 499 | 인기 아이돌 | 특별 컨셉/콜라보 해금 |
| A | 500+ | 톱 아이돌 | 데뷔 무대/한정 콘텐츠 해금 |

- 등급 폭: 60 → 90 → 150 → 200 → 700 (로그 곡선)
- 스탯은 누적만 됨 (감소/강등 없음)

### 1-3. 등급별 해금 콘텐츠

| 등급 | 해금 내용 |
|------|---------|
| F 연습생 | 기본 컨셉 3종 (School Life, Finger Heart, Daily) |
| D 신인 | Random 컨셉 + 컬렉션 기능 |
| C 루키 | 차트 참여 + 대결 |
| B 인기 | 특별 컨셉 (시즌 한정) + 콜라보 |
| A 톱 | 데뷔 무대 + 한정 포토카드 + 프리미엄 프레임 |

## 2. 연습하기 메뉴

### 2-1. 콘텐츠 목록

| 콘텐츠 | 상태 | 메인 스탯 | 확정 합계 |
|--------|------|----------|----------|
| **포토카드** | Active | 비주얼 +5, 매력 +2, 체력 +1 | +8 |
| 측면 이미지 | Locked | 비주얼 | Sprint 6 |
| 전신 이미지 | Locked | 비주얼 | Sprint 6 |
| 보이스 | Locked | 보컬 | Phase 2 후반 |
| 안무 | Locked | 댄스 | Phase 3 |

### 2-2. 횟수 정책

| 항목 | 내용 |
|------|------|
| 무료 횟수 단위 | **멤버별, 콘텐츠 타입별 독립 3회** |
| 범위 | 그룹/사용자 단위가 아닌 멤버 단위. 다중 그룹 소유 시에도 각 멤버별 독립 |
| Sprint 5 멤버당 무료 횟수 | 3회 (포토카드 3회. 타 콘텐츠는 해금 시 각각 3회 추가) |

### 2-3. 충전 플로우

> Sprint 5는 **기간 한정 무료**. 실제 결제는 전환율 데이터 검증 후 도입.

| 조건 | 동작 |
|------|------|
| 무료 3회 소진 후 생성 시도 | "추가 충전 필요" 다이얼로그 ("결제하기" / "나중에") |
| "결제하기" 클릭 | "현재 무료 체험 기간입니다" 안내 + 3회 충전 |
| 충전 후 소진, 재클릭 | "N시간 후 다시 충전할 수 있습니다" |
| 24시간 경과 후 클릭 | 3회 재충전 (반복 가능) |

- **무료 크레딧**: 멤버별, 타입별 독립 3회
- **충전 크레딧**: 사용자 단위 (멤버 간 공유)
- **소비 우선순위**: 해당 멤버 무료 먼저 → 충전 크레딧
- **목적**: 결제 전환율 측정 (클릭률 + 가격 기대치 형성)

### 2-4. 콘텐츠 공통 플로우와 타입별 차이

모든 콘텐츠 타입은 아래 공통 플로우를 따른다. 향후 콘텐츠 추가 시에도 동일한 구조를 적용한다.

**공통 플로우**:

1. 멤버 선택
2. 옵션 선택 (타입별 상이)
3. 보상 모드 선택 (확정/랜덤)
4. AI 생성 + 로딩 연출
5. 스탯 결과 연출
6. 저장/활용

**타입별 차이**:

| 항목 | 포토카드 | Side/Full-body | 보이스 |
|------|---------|---------------|--------|
| 선택 구조 | 컨셉 1가지 (4종) | 앵글 + 배경 + 스타일 (3단계) | 상황 + 대사(100자) + 톤 (3단계) |
| 결과 형태 | 카드형 이미지 (프레임 + 시리얼넘버) | 전신/측면 포토 (갤러리 저장) | 음성 파일 (재생/공유) |
| 수집 | 컬렉션 (레어/한정판) | 갤러리 저장 | 채팅 공유 / 프로필 인사말 설정 |
| 해금 시점 | Sprint 5 (Active) | Sprint 6 (?) | Phase 3 (?) |

## 3. 포토카드 드로우

### 3-1. 생성 플로우

1. **컨셉 선택** — 2x2 그리드 (School Life / Finger Heart / Daily / Random)
2. **모드 선택** — 확정 모드 (+8 고정) vs 랜덤 모드 (+2~+23)
3. **생성 중** — 로딩 애니메이션 (5~15초)
4. **결과** — Jackpot/Normal 분기 → 완성 카드 + 저장/다시만들기

### 3-2. 컨셉 옵션

| 컨셉 | 키워드 |
|------|--------|
| **School Life** | 교복, 캠퍼스, 청춘 |
| **Finger Heart** | 하트, 귀여움, 팬서비스 |
| **Daily** | 일상, 캐주얼, 자연스러움 |
| **Random** | AI가 랜덤으로 컨셉 생성 |

## 4. 보상 모드

### 4-1. 확정 모드

세션당 **+8 고정** (비주얼 +5, 매력 +2, 체력 +1). 예측 가능한 성장.

### 4-2. 랜덤 모드

| Grade | 확률 | Total |
|-------|------|-------|
| Miss | 30% | +2 |
| Normal | 35% | +8 |
| Great | 25% | +14 |
| Jackpot | 10% | +23 |

**EV(기대값) = 9.2** (확정 대비 +15%)

### 4-3. Near-Miss 연출

Miss 결과 시 30% 확률로 Near-Miss 연출 발동. Jackpot에 거의 도달하는 듯한 연출 후 Miss로 확정.

- 세션당 최대 1회 제한
- 일일 과금 한도 $50 설정

### 4-4. 등급별 애니메이션

> 아래 애니메이션 스펙은 초안이며, **프론트엔드 담당자와 상의가 필요합니다.**

상세 스펙은 [Sprint 5 상세 명세서](https://aidol-sprint5-deploy.vercel.app/)의 보상 모드 섹션 참고.

## 5. 포토카드 컬렉션

### 5-1. 진입 경로

- 멤버 프로필 스탯 탭 → "컬렉션" 버튼
- 포토카드 결과 화면 → 하단 "컬렉션 카드보기" 텍스트 링크

### 5-2. 화면 구성

- 멤버별 필터 (아바타 탭) + 컨셉별 필터 (가로 chip)
- 3열 카드 그리드, 최신순, NEW 뱃지 (24시간 내)
- 빈 슬롯(+) → 포토카드 드로우 이동
- 카드 탭 → 상세 (풀스크린 프리뷰 + 정보 + 삭제). **삭제해도 스탯은 유지**
