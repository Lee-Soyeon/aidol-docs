🏆 등급 체계 (F ~ A)

GradeRangeWidth타이틀설계 근거
F 0 ~ 59 60 연습생 무료 3회로 F 후반(~24) 도달. 추가 충전 시 빠른 탈출 가능. 빠른 초기 성취감 제공
D 60 ~ 149 90 신인 무료 3회 + 추가 충전으로 D 진입 가능. 첫 과금의 성취 지점. D→C는 추가 유료 필요
C 150 ~ 299 150 루키 첫 과금 관문. 약 2~3 5-Pack 구매 필요. 차트/대결 해금으로 동기부여
B 300 ~ 499 200 인기 아이돌 헤비 유저 영역. 특별 컨셉/콜라보 해금. 높은 충성도 구간
A 500+ 700+ 톱 아이돌 최상위 tier. 데뷔 무대/한정 콘텐츠 해금. 장기 목표

💰 무료 티어 성장 시뮬레이션

무료 유저 기준: 포토카드 무료 3회 (유일한 활성 콘텐츠) = 총 3회 세션

총 획득: 3 × 8 = ~24 stats → F 등급 후반

랜덤: 1~2×3회충전 = $0.99~$1.98
D → C (150)90 추가~12 세션~10 세션확정: 4×3회충전 = $3.96
랜덤: 3~4×3회충전 = $2.97~$3.96

💳 충전 플로우

Sprint 5는 기간 한정 무료. 실제 결제는 전환율 데이터 검증 후 도입.

조건동작
무료 3회 소진 후 생성 시도"추가 충전 필요" 다이얼로그 ("결제하기" / "나중에")
"결제하기" 클릭"현재 무료 체험 기간입니다" 안내 + 3회 충전
충전 후 소진, 재클릭"N시간 후 다시 충전할 수 있습니다"
24시간 경과 후 클릭3회 재충전 (반복 가능)
  • 무료 크레딧: 멤버별, 타입별 독립 3회
  • 충전 크레딧: 사용자 단위 (멤버 간 공유)
  • 소비 우선순위: 해당 멤버 무료 먼저 → 충전 크레딧
  • 목적: 결제 전환율 측정 (클릭률 + 가격 기대치 형성)

🗺 네비게이션 플로우

1
내그룹 → 연습하기

내그룹 화면에서 "연습하기" 버튼 탭

2
멤버 선택

상단 멤버 셀렉터에서 대상 멤버 선택 (기본: 마지막 선택 멤버)

3
포토카드 선택 (유일한 활성 콘텐츠)

포토카드 메뉴 탭 → 생성 플로우 진입. Locked 아이템 탭 → "곧 해금됩니다" 토스트

4
컨셉 선택

School Life / Finger Heart / Daily / Random 중 하나 선택

5
"만들기" 버튼 탭

컨셉 선택 후 "만들기" 버튼으로 생성 시작

6
횟수 있음 → 모드 선택 → 생성

횟수 남아있으면 모드 선택 바텀시트 (확정/랜덤) 노출 후 생성 진행

7
횟수 없음 → "결제하기" 다이얼로그

횟수 소진 시 "결제하기" 버튼 노출. 클릭 시 "무료 체험 기간" 안내 + 3회 충전 / 소진 후 재클릭: 24시간 쿨다운

8
충전 후 → 모드 선택 → 생성

충전 크레딧은 사용자 단위 (멤버 간 공유). 소비 시 해당 멤버 무료 먼저 → 충전 크레딧 순

9
결과 → 저장

완성된 포토카드 표시 + 스탯 상승 + "저장하기" / "다시 만들기" 버튼

Grade연출Duration효과음
Miss 카드 살짝 흔들림 + 회색 파티클. 숫자 fade-in (작게). 약간의 실망감 연출 800ms 낮은 톤 "뚜둥"

Jackpot 화면 플래시 → 카드 3D 회전 등장 → 무지개 파티클 폭발 → 숫자 크게 바운스 + 화면 셰이크. "JACKPOT!" 풀스크린 오버레이 (2초) 3500ms 드럼롤 → 팡파레 → 관중 열광

🔥 Near-Miss 연출 (심리 장치)

Miss 결과 시 30% 확률로 "Near-Miss" 연출 발동. 잠시 Great/Jackpot 결과가 보이다가 Miss로 확정되는 연출. 다음 시도에 대한 동기 부여 효과.
1
스피너 시작 (600ms)

Miss → Normal → Great → Jackpot 순서로 빠르게 로테이션

2
감속 (800ms)

Great 또는 Jackpot에서 잠시 멈추는 듯한 연출. 기대감 최고조

3
최종 확정 (400ms)

Miss로 슬라이드. "아쉽게 놓쳤어요!" 텍스트. 다음 도전 유도 CTA 강조

윤리적 고려: Near-miss는 슬롯머신의 심리 기법. 과도한 과금 유도를 방지하기 위해 near-miss 연출은 세션당 최대 1회로 제한. 일일 과금 한도($50) 설정과 함께 운용.
