### 1.1 스크립트 성격 및 구조적 특성

이 스크립트는 Fireflies STT 자동 변환 기반 원문이다. 피실험자(송선재, U14)가 직접 발화한 녹취록이 아니라, 피실험자의 동생(eunjae song)이 UT 진행 후 소연(Soyeon Lee)과의 피드백 미팅에서 UT 결과를 2차 전달하는 구조이다.

- 피실험자(송선재) 발화는 직접 녹음되지 않았다. 모든 피실험자 발화는 은재의 전언이다.

- 소연의 리액션 및 확인 질문이 피드백 방향을 유도하는 경우가 있다.

### 3.2 핵심 행동 패턴

1. **창작 욕구의 즉각적 발현**: 프리셋 목록을 3초 보고 스킵, 5명 전원 신규 생성. 주어진 것을 고르는 것보다 직접 만드는 것이 본능적 선택.

2. **이미지 생성이 몰입의 핵심 트리거**: MBTI 설정 단계는 신중하게 진행했으나, 이미지 결과물이 나왔을 때 자세를 고쳐앉는 비언어 행동으로 몰입 피크가 명확하게 확인됨.

3. **서사 투자의 역설**: 서사를 굉장히 자세하게 작성했으나(농구 선수, 아역 배우, 유학 등), 그 직후 그룹명 단계에서 이탈을 고려함. 서사 투자가 캐릭터 애착을 만들었지만, 비가역적 다음 단계(그룹명)에서 리스크 인식이 급증.

4. **비주얼 완성도 추구**: 이미지 재생성 망설임, 엠블럼 여러 번 재생성. 비주얼 요소에 높은 완성도 기준 적용.

5. **관계성 자발적 동기 부재 + 설명 후 전환**: "얘네의 관계성을 다 만들어야 돼?"라고 초기 거부했으나, 채팅 반영 설명 후 5명 전원 완성. 가치를 화면 내에서 스스로 발견하지 못함.

6. **소유감 기반 콘텐츠 소비 의향**: 타 그룹 콘텐츠 무관심. 내가 만든 그룹의 콘텐츠만 기대. 소유감이 콘텐츠 소비 의향의 전제 조건.

### Theme 1: 창작 주체성 — "고르는 것"보다 "만드는 것"

- 관련 코드: `캐스팅-스킵`, `신규생성-선택`, `창작욕구-강함`, `캐릭터기획-인지`, `서사-자세작성`, `캐릭터-서사부여`, `포지션-트렌드논리`, `엠블럼-반복재생성`
- 근거: VC-01, VC-02, VC-07, VC-08, VC-10, VC-20
- 요약: U14는 프리셋 목록을 3초 보고 즉시 스킵, 5명 전원 신규 생성을 선택했다. 이는 "선택"이 아닌 "제작"을 원하는 욕구이다. MBTI를 퍼센트 단위까지 고민하고, 서사를 농구 선수/아역 배우/유학 등 구체적으로 작성하고, 엠블럼을 여러 번 재생성하는 행동은 이 창작 주체성이 세션 전반에 걸쳐 일관되게 나타남을 보여준다. "이 멤버의 얼굴을 미리 상상을 하고 어떤 성격이 어울릴지"라는 발화는 제작 행위가 단순 설정 입력이 아닌 캐릭터 기획이라는 인지 구조를 보여준다.

### Theme 2: 이미지 결과물이 유일한 몰입 트리거

- 관련 코드: `이미지결과-충격`, `자세고쳐앉음`, `몰입-피크`, `기대초과`, `AHA-트리거`, `재생성-망설임`, `이미지유실-불안`, `손실회피`, `비주얼/프로필-선호`, `비주얼-집착`, `프로필사진-작음`
- 근거: VC-03, VC-05, VC-10, VC-18, VC-19
- 요약: "처음에 언니가 기대를 안 하고 있다가 결과물이 딱 나오니까 엄청 집중도 확 올라가면서 이렇게까지 잘 나올 줄 몰랐다고 본인이 상상하던 그대로 나왔다고" — 이 한 문장이 세션 전체의 감정 정점을 설명한다. 이미지 생성 결과물은 단순한 UI 요소가 아니라 서비스 전체 가치를 결정하는 핵심 매체이다. 반대로 이미지를 재생성하면 기존 이미지가 사라진다는 사실이 이탈 포인트로 작동한다. 타 그룹 콘텐츠에서도 텍스트보다 "어떤 멤버가 있는지", "얼굴이 잘 보이는지"를 더 중요시하는 것도 같은 맥락이다.

### Theme 3: 비가역적 결정 앞의 이탈 위기

- 관련 코드: `그룹명-수정불가인지`, `이탈고려`, `책임감-과부하`, `UX문제-비가역`, `이탈포인트`, `재생성-망설임`, `이미지유실-불안`
- 근거: VC-05, VC-09
- 요약: "나중에 수정도 안 될 것 같아서 이때 약간 포기할까 조금 생각을 했었던 것 같아요. 스텝에서 이제 책임이 너무 커지니까 여기서 이제 좀 중단할까라는 이렇게 마음을 조금 표현" — 이 유저는 창작에 깊이 투자하기 때문에, 그 투자가 비가역적 결정으로 고착될 가능성이 보이는 순간 이탈을 고려한다. 이미지 재생성 망설임과 그룹명 이탈 고려 모두 같은 심리 구조이다: "내가 투자한 것을 잃을 수 있다"는 손실 회피.

### Theme 4: 관계성은 외부 설명 없이 자발적으로 동기 부여되지 않는다

- 관련 코드: `관계성-초기거부`, `필요성-미인지`, `설명후-완성`, `자발적동기-없음`, `관계성-필요성-외부설명의존`, `채팅반영-설명후동기`
- 근거: VC-13, VC-15
- 요약: "얘네의 관계성을 다 만들어야 돼?" "이게 내가 즐길 수 있을까" — 관계성 기능이 채팅/콘텐츠에 반영된다는 설명을 듣기 전까지 피실험자는 이 기능의 필요성을 전혀 인지하지 못했다. 설명 후에는 5명 전원 완성할 만큼 적극성을 보였다는 점에서, 문제는 관심 부재가 아니라 기능의 가치가 UI 내에서 자명하지 않다는 것이다. 이 구조는 U10(최지윤)과 달리 "설명하면 한다"는 점이 특징적이다.

### Theme 5: 소유감은 콘텐츠 소비의 전제 조건이다

- 관련 코드: `내그룹-콘텐츠기대`, `타그룹-무관심`, `UGC-무관심`, `소유감-콘텐츠연결`, `URL공유-요청`, `이메일-미입력`
- 근거: VC-11, VC-16, VC-17, VC-18, VC-19
- 요약: "본인이 만든 그룹의 콘텐츠는 언제 볼 수 있느냐" — 타 그룹 콘텐츠에는 전혀 관심이 없었고, 자신이 만든 그룹의 콘텐츠를 먼저 기다렸다. 이는 "소유감이 있는 그룹에만 콘텐츠 소비 의향이 생긴다"는 강력한 패턴이다. 완성 화면에서 URL만 요청하고 이메일을 입력하지 않은 것은 만족감은 있었으나 재방문으로 전환되는 추가 동기가 없었다는 것과 같은 맥락이다.

| 콘텐츠 선호 | 내 그룹 콘텐츠 우선. 타 그룹 텍스트 콘텐츠 무관심. 비주얼/프로필 중심 선호. |
| AI 인식 | AI이기 때문에 더 자유롭게, 더 도전적으로 만들 수 있다는 인식 (젠더리스 등) |
| 핵심 발화 | "본인이 상상하던 그대로 나왔다" (자세 고쳐앉음) / "얘네 관계성을 다 만들어야 돼?" |
| U10 대비 차이점 | U10은 비주얼 투자 + 텍스트 회피의 분리. U14는 비주얼 + 텍스트 서사 모두 깊이 투자하는 창작형. 단, 관계성은 둘 다 자발적 동기 없음. |

## 10. Mental Model Gap Analysis

### Gap 1: 프리셋 캐스팅 = 선택의 즐거움 vs 프리셋 = 창작 욕구를 방해하는 것

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 프리셋 연습생 = 다양한 선택지 제공 -> 선택 행위로 애착 유발 (H1 가설) | 프리셋은 "내가 만들고 싶은 것"이 아님. 3초 보고 즉시 스킵. |
| 캐스팅 + 직접 생성 혼합 플로우 | 직접 생성이 전부여야 의미가 있음. 캐스팅은 대안이 아닌 방해 요소. |

**영향**: H1("캐스팅만으로 애착")은 이 유저에게 작동하지 않는다. 프리셋 캐스팅 단계 자체가 동기를 소모시키는 마찰이 된다. 창작 성향 세그먼트에게는 프리셋을 최소화하거나, 직접 생성을 디폴트로 설계할 필요가 있다.

### Gap 2: 이미지 재생성 = 개선 시도 vs 이미지 재생성 = 기존 결과물 유실 위기

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 재생성 버튼 = 더 좋은 결과물로 개선하는 기회 | 재생성 = "지금 이미지가 없어지는 것". 더 나빠질 수 있다는 손실 회피 |
| 재생성은 단순한 재시도 | 재생성 전 현재 이미지를 확정해야 안심. 히스토리 없이는 리스크 |

**영향**: 재생성 망설임은 이 유저가 이미지에 이미 높은 가치를 부여하고 있다는 신호이다. 재생성 시 이전 이미지를 보관하거나 비교 선택할 수 있는 구조가 없으면, 높은 투자 의지를 가진 유저가 오히려 행동을 멈추는 역설이 발생한다.

### Gap 3: 그룹명 = 브랜딩 단계 vs 그룹명 = 되돌릴 수 없는 영구 결정

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 그룹명 = 창작 과정의 자연스러운 한 단계 | 그룹명 = 수정 불가 = 잘못 지으면 모든 투자가 무효가 되는 결정 |
| UI에서 수정 가능 여부를 명시하지 않음 | "수정도 안 될 것 같아서" — 인지적으로 비가역적으로 해석 |

**영향**: 실제로 수정 가능 여부와 무관하게, "수정 불가"로 인지하는 것만으로도 이탈을 고려한다. UI에서 수정 가능성을 명시하거나, 실제로 수정 가능하게 하는 것이 모두 해결책이 될 수 있다.

### Gap 4: 관계성 = 세계관 완성의 중요한 요소 vs 관계성 = "왜 해야 하는지 모르는 선택적 작업"

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 관계성이 채팅/콘텐츠에 반영됨 -> 서비스 가치의 핵심 | "이게 내가 즐길 수 있을까" — 가치가 자명하지 않음 |
| 관계성 설정이 완성을 위한 자연스러운 다음 단계 | "얘네 관계성을 다 만들어야 돼?" — 필수인지 선택인지도 불명확 |

**영향**: 관계성 기능 자체에 대한 거부가 아니라 "왜 해야 하는지" 모른다는 것이 문제이다. U14는 설명을 들은 후 5명 전원을 완성했고, 복합 유형까지 요청했다. 관계성 화면 진입 시 "이 관계성이 채팅/콘텐츠에 반영됩니다"라는 인라인 안내 한 줄이 완성률을 극적으로 높일 수 있다.

### Gap 5: 타 그룹 하이라이트 = 서비스 콘텐츠 발견 경험 vs 타 그룹 하이라이트 = 나와 무관한 콘텐츠

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 하이라이트 = 다양한 그룹 스토리를 발견하며 세계 확장 | "다른 그룹 콘텐츠를 먼저 찾아볼 것 같지 않다" |
| 텍스트 기반 하이라이트가 스토리 전달 | 처음에 이게 무엇인지 이해 못함. 읽어도 너무 짧아서 아쉬움. |

**영향**: 소유감이 없는 그룹의 콘텐츠는 이 유저에게 가치가 없다. 타 그룹 탐색을 동기로 하는 피드 설계보다, 내가 만든 그룹의 콘텐츠를 빠르게 경험하게 하는 것이 이 세그먼트에게 적합하다.

## 11. Norman's 7 Stages of Action

### 11.1 Goal (목표)

- **유저 목표**: 내가 상상하는 아이돌 캐릭터를 AI로 구현하고, 그 결과물을 소유하며, 내 그룹의 콘텐츠를 즐기고 싶다.
- **시스템 목표**: 캐스팅 -> 신규 생성 -> 포지션 -> 그룹명 -> 엠블럼 -> 관계성 -> 하이라이트 콘텐츠 소비

### 11.2 Execution Side (실행)

| 단계 | 분석 |
|------|------|
| Plan (계획) | 프리셋 목록을 보자마자 "내가 직접 만들겠다"는 계획으로 즉각 전환. 사전에 원하는 캐릭터 유형의 비전이 있음. |
| Specify (구체화) | MBTI 슬라이더 퍼센트 단위 설정. 이미지 프롬프트 "아랍상, 눈썹 진함, 쌍꺼풀, 포마드 헤어, 20대 남성 한국 아이돌". 서사를 농구 선수/아역 배우/유학 등 구체적으로 작성. |
| Perform (수행) | 5명 전원 신규 생성 -> MBTI 설정 -> 이미지 생성 -> 서사 작성 -> 포지션 배정 -> 그룹명 (이탈 고려 후 완성) -> 엠블럼 반복 재생성 -> 관계성 (설명 후) -> 완성 |

### 11.3 Evaluation Side (평가)

| 단계 | 분석 |
|------|------|
| Perceive (인지) | 이미지 결과물 즉각 확인 -> "기대를 안 하고 있다가 결과물이 딱 나오니까 엄청 집중도 확 올라가면서" (정확한 인지, 빠른 반응) |
| Interpret (해석) | "상상하던 그대로 나왔다" — 기대와 결과 일치. 자세 고쳐앉음. 이후 다음 멤버 열심히 상상. |
| Compare (비교) | 이미지: 기대 초과 만족. 스타일링: 부분 불만. 그룹명 수정 가능성: 부정적 가정 (비가역으로 인지). 관계성 가치: 불명확 (설명 전). 하이라이트 콘텐츠: 처음에 이해 불가. |

### 11.4 Gulf of Execution (실행의 간극)

- **이미지 재생성**: 재생성 = 기존 유실이라는 공포가 실행을 막음. 히스토리 기능 없이는 높은 투자 의지가 행동 장벽이 됨.
- **그룹명 단계**: "수정 불가"로 인지 -> 포기 고려. 실제 수정 가능 여부와 무관한 인지 장벽.
- **관계성 진입**: 왜 해야 하는지 모름 -> 초기 거부. 설명이 있어야 실행 가능.

### 11.5 Gulf of Evaluation (평가의 간극)

- **하이라이트 콘텐츠**: "이게 어떤 건지 처음에 확 와닿지 못했던 것 같아요" — 콘텐츠의 성격이 화면에서 자명하지 않음.
- **관계성 기능**: 설정 화면만 보고는 채팅/콘텐츠 반영 여부를 알 수 없음 -> 가치 인지 불가.

## 12. Norman's 3 Levels of Design

### 12.1 Visceral Level (본능적 반응)

- **강한 긍정**: 이미지 결과물이 상상 그대로 나왔을 때 — "기대를 안 하고 있다가 결과물이 딱 나오니까 엄청 집중도 확 올라가면서", 자세 고쳐앉음
- **약한 부정**: 이미지 생성 속도가 느릴 때 (대기 중 집중도 저하), 처음 하이라이트 콘텐츠를 봤을 때 (이게 뭔지 모르는 당혹감)
- **시사점**: Visceral 레벨에서 이미지 품질과 생성 속도가 첫인상을 결정한다. 이미지가 상상과 일치하는 순간 서비스 전체 신뢰도가 급상승한다.

### 12.2 Behavioral Level (행동적 반응)

- **긍정**: MBTI 슬라이더, 프롬프트 작성, 서사 작성, 엠블럼 재생성 모두 자연스럽게 수행. 관계성은 설명 후 완성.
- **부정/마찰**:
  - 이미지 재생성 버튼 앞에서 망설임 (기존 유실 불안)
  - 그룹명 단계에서 포기 고려 (비가역 인지)
  - 관계성 진입 시 초기 거부 (가치 불명확)
  - 하이라이트 콘텐츠 이해 지연 (성격 불명확)
- **시사점**: Behavioral 레벨에서 마찰 포인트는 "비가역"과 "가치 불명확"이라는 두 구조적 문제에 집중되어 있다. 이 두 문제를 해결하면 플로우 전반의 행동 완성도가 높아진다.

### 12.3 Reflective Level (반성적 반응)

- **긍정**: "본인이 상상하던 그대로 나왔다" — 창작 행위가 가치 있는 경험이었다는 반성적 평가. 내 그룹의 콘텐츠를 기다리는 행동은 소유감이 Reflective 레벨에서 작동하고 있음을 보여줌.
- **AI에 대한 긍정적 재인식**: "AI라서 오히려 이런 게 더 자유롭고 도전적인 걸 만들고 싶다" — AI 매체 자체를 창작 가능성의 확장으로 인식.
- **부정**: 이메일 미입력 + URL만 공유 요청 — 완성 경험은 긍정이지만, 재방문을 유도하는 Reflective 동기가 없음. "이 경험을 내일도 이어가야 한다"는 동기가 부재.
- **시사점**: Reflective 레벨에서 창작 성취감은 형성되었으나, 지속 사용의 동기로 연결되지 않고 있다. "내 그룹의 콘텐츠가 나온다"는 예고가 있으면 재방문 동기를 만들 수 있다.

## 13. Hypothesis Validation (가설 검증)

### Sprint 1 가설

### H1: 유저는 캐스팅만으로도 애착을 느낀다

| 판정 | 반대 (이 유저에게) |
|------|------------------|
| 근거 - 반대 | 프리셋 목록 3초 보고 즉시 스킵. 5명 전원 신규 생성 선택. "입맛에 맞는 그 생성을 더 하고 싶어하는 의지" (VC-01). |
| 근거 - 보충 | 애착 형성의 근거는 모두 직접 생성한 캐릭터에 있다 (서사 자세 작성, 이미지 결과물 만족, 내 그룹 콘텐츠 기대). 프리셋 캐스팅 단계가 존재하지 않는 것과 같이 행동함. |
| 조건 | 이 세그먼트(창작 성향, AI 이미지 숙련자)에게 H1은 작동하지 않는다. 직접 생성이 애착의 필수 전제 조건. |

### H2: 유저는 결과물보다 선택 과정에 의미를 둔다

| 판정 | 부분 지지 (과정에 의미를 두되, 제작 과정에 한정) |
|------|-------------------------------------------|
| 근거 - 지지 | MBTI 퍼센트 단위 설정, 서사 자세 작성, 엠블럼 반복 재생성. 과정에 높은 투자를 하고 있음. |
| 근거 - 수정 | H2의 "선택 과정"은 캐스팅/선택이 아닌 "제작 과정"에 한정된다. 이 유저는 결과물(이미지)과 제작 과정(서사, MBTI, 엠블럼) 모두에 의미를 둔다. |
| 조건 | "과정 = 제작 행위"일 때 지지. "과정 = 프리셋 중 선택"이라면 반대. |

### H3: 이메일 입력은 기대 행동이다

| 판정 | 반대 |
|------|------|
| 근거 | 완성 화면에서 URL 공유만 요청. 이메일 미입력. 다른 그룹 생성 없음. (VC-11) |
| 해석 | 완성 자체에 대한 만족은 있으나, 이메일 입력 = 재방문 기대라는 연결 고리가 없음. "이메일을 남기면 무엇을 받을 수 있는가"가 자명하지 않거나 매력적이지 않음. |

### Sprint 2 가설

### H4: 세계관 수정 행동은 애착을 강화한다

| 판정 | 조건부 지지 (설명 필요 조건 전제) |
|------|--------------------------------|
| 근거 - 지지 | 설명 후 5명 전원 관계성 완성. 복합 유형까지 요청. 완성 후에는 깊이 있는 창작 태도 유지. |
| 근거 - 약화 | 설명 없이는 자발적으로 진입하지 않음. "얘네 관계성을 다 만들어야 돼?" "이게 내가 즐길 수 있을까" (VC-13, VC-15). 세계관 수정이 애착 강화로 이어지는 것은 "기능의 가치를 이해한 이후"에만 성립. |
| U10 대비 | U10(최지윤)은 설명을 들어도 발전 욕구 1점 ("어려워요, 생각하기 싫어요"). U14는 설명 후 전원 완성 + 복합 유형 요청. 동일한 "설명 필요"라는 문제지만 반응 결과가 다름. |
| 조건 | **H4는 설명/안내가 있을 때만 성립. 안내 없으면 진입 자체가 안 됨.** |

### H5: 스토리 소비 후 세계관 화면 이동이 발생한다

| 판정 | 검증 불충분 (순서 상이) |

## 15. Cross-Analysis Summary

### 15.1 핵심 인사이트 5선

**1. 이미지 결과물 품질이 서비스 전체 가치를 결정한다**

"처음에 기대를 안 하고 있다가 결과물이 딱 나오니까 엄청 집중도 확 올라가면서 이렇게까지 잘 나올 줄 몰랐다고 본인이 상상하던 그대로 나왔다고" — 이 한 문장이 U14 세션 전체를 설명한다. 이미지가 기대를 충족했을 때 세션 몰입도가 비선형적으로 급상승했다. 반대로 이미지 재생성 시 기존 유실 불안이 가장 높은 몰입 단계에서 행동을 막는 역설도 이 맥락에서 이해된다.

액션: 이미지 초기 생성 품질을 높이는 것이 최우선 개발 과제. 재생성 히스토리 기능이 단순 편의가 아닌 핵심 플로우 안전망.

**2. 창작 성향 유저에게 프리셋 캐스팅은 마찰이다**

5명 전원 신규 생성, 프리셋 3초 스킵이라는 행동은 단순한 선택 결과가 아니라 이 유저가 서비스에 가지는 기대 자체를 보여준다. "내가 만든 것"이어야 가치가 있다는 전제에서 시작하는 이 유저에게, 프리셋 목록은 "내가 원하는 것이 아닌 것들"의 집합이다.

액션: 창작 성향 세그먼트(B그룹)에게는 신규 생성을 디폴트로 제안하거나, 프리셋 목록과 신규 생성 진입점의 배치를 세그먼트별로 분기할 것.

**3. 비가역적 결정에서의 이탈 위기 — 창작 투자가 클수록 이탈 위험도 크다**

서사를 자세하게 쓰고 MBTI를 신중하게 설정한 이후, 그룹명에서 포기를 고려한다는 것은 역설적이다. 창작에 더 많이 투자할수록, 그 투자가 비가역적 결정으로 고착될 가능성 앞에서 더 강한 이탈 충동이 발생한다. 이는 고투자 유저일수록 UX 안전망이 더 필요하다는 의미이다.

액션: 그룹명 수정 가능 기능 제공, 또는 "그룹명은 나중에 수정할 수 있습니다" 인라인 안내. 이미지 재생성 히스토리도 같은 구조의 해결책.

**4. 관계성은 "필요성을 알아야 완성된다" — 온보딩 문구 한 줄의 효과**

"이게 내가 즐길 수 있을까"에서 시작한 유저가 "채팅에 반영된다"는 설명 한 줄을 듣고 5명 전원 관계성을 완성했다. 복합 유형(라이벌+친함, 동경+어려움)까지 요청할 만큼 적극적으로 바뀌었다. 이것은 기능의 매력이 없는 것이 아니라, 기능의 가치가 화면 내에서 자명하지 않다는 것을 보여준다. U10(최지윤)과 달리 U14는 설명을 들으면 행동한다.

액션: 관계성 진입 화면에 "이 관계성은 채팅과 콘텐츠에 반영됩니다" 인라인 안내 추가. 설명을 언어로 하는 것이 아니라 화면에서 보여줘야 UT 없이도 완성률이 보장된다.

**5. 소유감이 전제되어야만 콘텐츠 소비 의향이 생긴다**

"본인이 만든 그룹의 콘텐츠는 언제 볼 수 있느냐" — 이 발화는 내가 만든 그룹에 대한 콘텐츠 기대를 표현하는 동시에, 타 그룹 콘텐츠에는 전혀 관심이 없다는 것을 대비로 보여준다. 이 유저의 콘텐츠 소비 의향은 소유감을 전제로 성립한다. 소유감 없는 콘텐츠 피드는 이 세그먼트에게 가치가 없다.

액션: Sprint 3에서 "내가 만든 그룹의 콘텐츠를 먼저 보여주는 구조"를 디폴트로. 타 그룹 피드는 내 그룹 콘텐츠 소비 이후의 선택적 탐색으로.

### 15.5 분석 제약 사항

- 이 UT는 피실험자(송선재)의 직접 발화가 아닌 동생(은재)의 2차 전달 구조로 진행되었다. 모든 발화는 은재의 관찰과 해석이 개입된 결과이며, 피실험자의 실제 정서, 뉘앙스, 강도를 정확히 재현하지 못할 수 있다.
- 피실험자는 AI 이미지 생성 숙련자(프롬프트 작성 경험 다수)이다. 일반 사용자는 프롬프트 작성 단계에서 더 큰 마찰을 경험할 수 있으며, 이 유저의 몰입 피크(이미지 결과물 만족)가 일반 사용자에게도 동일하게 재현된다는 보장이 없다.
- 결제 의향에 대한 질문/발화가 없었다. Sprint 3 UT에서 반드시 확인 필요.
- "내 그룹 콘텐츠는 언제 볼 수 있느냐"는 발화는 Sprint 3(채팅)에 대한 강한 기대를 보여주지만, 실제 채팅 경험 후 재방문 여부는 미검증 상태이다.
