## 2. Verbatim Extraction & Coding

원본 analysis summary에서 추출한 핵심 발화. 각 발화에 분석 코드를 부여한다.

### VC-01 [블라인드 UI 반응 — 선택 행위 인식]

> "계약 완료된 애들은 블라인드 처리돼서 안 보였으니, 남은 애들 중에 고민해서 직접 선택했으니까"

- 코드: `선택행위-인식` `블라인드UI-반응` `H2-지지` `직접선택-체감`
- 해석: 블라인드 처리라는 UI 요소가 "남은 후보 중 고민"이라는 선택 행위 인식을 강화했음. 단, 선택 고민의 원인이 UI 설계인지 개인 성향(결정장애)인지 분리 불가.

### VC-02 [그룹 아쉬움 이유 — 시간 투자 귀인]

> "내가 직접 고르는데 투자된 시간이 있으니까, 내가 캐스팅한 그룹이 통째로 막상 다른 유저가 가져가면 아쉽지"

- 코드: `아쉬움-시간투자귀인` `조합단위-애착` `개별멤버-애착-부재` `H1-약화` `소유감-과정기반`
- 해석: Q4 아쉬움 4점의 이유가 멤버 개별 애착이 아니라 "투자된 시간"임. 감정적 애착이 아닌 매몰 비용 효과에 가까운 반응.

### VC-03 [역문항 반응 — 육성 전환]

> "랜덤으로 주어진다고 하더라도, (육성형 서비스라면) 어쨌든 잘 키우면 될 것."

- 코드: `역문항-수용적` `육성-핵심동인` `캐스팅-부차적` `H1-조건부` `애착-육성과정기대`
- 해석: Q3 역문항 3점. 캐스팅 선택보다 육성 과정에서 애착이 형성될 것이라는 기대가 더 강하게 작동함. 선택보다 과정(육성)이 핵심.

### VC-04 [육성 욕구 — 등급 성장 서사]

> "훈련시키고 C 등급으로 A등급으로 만들고 싶음"

- 코드: `육성욕구-등급성장` `성장서사-핵심동인` `제작자-포지션` `프로듀스101-레퍼런스`
- 해석: 프로듀스 101 F→A 성장 서사에 대한 레퍼런스와 함께 등장. 단순 콘텐츠 소비가 아닌 능동적 성장 서사 제작 욕구.

### VC-05 [서사 중요성 — 서바이벌 서사 프레임]

> "서바이벌 프로그램에서 서사가 반을 먹고 들어감. 서사 없으면 사라져도 잘 모름"

- 코드: `서사-필수요소` `서바이벌-프레임` `캐릭터-존재감-서사의존` `콘텐츠구조-비판`
- 해석: 서사가 없는 캐릭터는 사라져도 인식조차 못 한다는 강한 발언. 현재 서비스의 서사 부재가 리텐션 위험으로 직결됨을 인식하고 있음.

### VC-06 [콘텐츠 한계 — 육성 없는 구조의 한계]

> "육성이 메인이고 사이사이 얘네가 어떤 일들이 있었는지 궁금한 거지 그것만 기능이 있으면 어느 순간 질려버릴 것임"

- 코드: `콘텐츠-육성보조` `질림-경고` `리텐션위험` `육성-메인구조-요구` `콘텐츠단독-부족`
- 해석: 콘텐츠는 육성 서사의 부산물로 포지셔닝되어야 의미 있음. 콘텐츠 단독 기능으로는 리텐션 불가능하다는 직접적 경고.

### VC-07 [콘텐츠 소비 한계 — AI 아이돌 전제]

> "AI 아이돌이라는 전제가 있다보니 콘텐츠를 보는 것에 한계가 생겨버림"

- 코드: `AI아이돌-전제-한계` `콘텐츠소비-심리장벽` `원인-미분리` `B그룹-관점`
- 해석: AI 아이돌이라는 속성 자체가 콘텐츠 소비의 심리적 한계를 만드는지, 현재 콘텐츠 퀄리티 문제인지 원인 미분리. B그룹(비팬) 관점에서 나온 중요 발언.

### VC-08 [세계관 수정 후 추가 개입 욕구]

> (관계성 설정 완료 후) "딴 거 있으면 더하고 싶음"

- 코드: `추가개입욕구` `기능범위-불충분` `제작욕구-확장` `H4-지지` `세계관기능-제한`
- 해석: 현재 관계성 설정 기능만으로는 제작 욕구를 충족하지 못함. 추가 편집 요소에 대한 직접 요청.

### VC-09 [소유감 — 성공 서사 조건부 전환]

> "예나를 데리고 다른 사람이 슈퍼스타가 되면 원래 내 거였는데"

- 코드: `소유감-조건부` `성공서사-소유감전환` `소급소유감` `H4-부분` `예나-언급`
- 해석: Q 소유감 2점이나, 성공 서사 발생 시 소급 소유감이 전환될 가능성을 스스로 표현. 현재 소유감과 미래 소유감이 분리됨.

### VC-10 [제작자 포지션 인식]

> "얘네가 블랙핑크처럼 크면 뿌듯할 것 같음. 제작자 입장에서."

- 코드: `제작자-포지션` `성공예측-뿌듯함` `IP제작-인식` `H7-지지` `B그룹-제작자프레임`
- 해석: "제작자 입장에서"라는 표현을 스스로 사용. IP 제작 인식이 자발적으로 형성됨. B그룹의 창작 성향이 제작자 프레임으로 자연스럽게 활성화됨.

### VC-11 [스토리 소비 후 세계관 이동 — 비하인드 욕구]

> "유경-예나 이야기 궁금해, 비하인드 스토리니까"

- 코드: `비하인드욕구` `멤버간-관계서사` `H5-지지` `스토리-세계관연결` `관계서사-관심`
- 해석: 특정 멤버(유경-예나) 간의 관계 서사에 대한 호기심이 세계관 이동 동인으로 작용. H5(스토리 소비 후 세계관 이동) 지지 근거.

## 3. Behavioral Sequence Analysis

### 3.1 조수연 행동 시퀀스

```
[Sprint 1 - 캐스팅 플로우]
-> 캐스팅 진입
   계약 완료 멤버 블라인드 처리 상태 확인
   [관찰] 블라인드 UI가 "남은 후보 중 고민" 행동 유발
-> 캐스팅 고민 및 선택 (Q1: 5점)
   결정장애 개인 성향으로 귀인
   [관찰] 고민 원인 분리 불가 (UI 설계 vs 개인 성향)
-> '내가 선택했다' 체감 확인 (Q2: 5점)
-> 역문항 응답 (Q3: 3점)
   "랜덤으로 주어져도 잘 키우면 됨"으로 육성으로 시선 전환
   [관찰] 선택 자체보다 육성 과정에 대한 기대가 강하게 작동

   [관찰] 멤버 개별 애착이 아닌 조합 단위 + 투자 시간 기반

[Sprint 2 - 세계관 개입 플로우]
-> 관계성 설정 수행
   완료 후 "딴 거 있으면 더하고 싶음" 발언
   [관찰] 기능 범위 불충분 — 추가 개입 욕구 즉각 표현
-> 제작 인식 응답 (제작 인식 4점)
   "내가 만든 설정에 가깝다" 4점
   [관찰] 최소 개입으로도 제작 행위 인식 발생
-> 세계관 구체화 욕구 확인 (5점)
   프로듀스 101 F→A 서사 레퍼런스로 육성 욕구 표현
   "훈련시키고 C 등급으로 A등급으로 만들고 싶음"
-> 소유감 응답 (2점)
   "예나를 데리고 다른 사람이 슈퍼스타가 되면 원래 내 거였는데" 발언
   [관찰] 현재 소유감은 낮으나 성공 서사 발생 시 소급 전환 가능성 신호
-> 설정 수정 재미 (5점)
-> 제작자 포지션 인식 자발적 표현
   "얘네가 블랙핑크처럼 크면 뿌듯할 것 같음. 제작자 입장에서."
```

### 3.2 핵심 행동 패턴

1. 선택 행위는 인식되나 개별 멤버 애착으로 미전환: 고민과 선택감 점수(5/5)는 높으나 "한 명씩 사라지는 건 상관없다" 발언이 공존. 애착 대상이 멤버 개인이 아닌 조합 단위 + 투자 시간.
2. 모든 욕구가 육성 서사 방향으로 수렴: 캐스팅, 세계관, 콘텐츠 모든 접점에서 반응이 육성/성장 서사로 수렴됨. "랜덤이어도 잘 키우면 됨", "C→A 성장 서사", "서사가 반을 먹고 들어감"이 일관된 패턴.
3. 세계관 수정 후 즉각 추가 개입 요구: 관계성 설정 완료 직후 "딴 거 있으면 더하고 싶음" 발언. 충족 후 확장을 요구하는 패턴 — 현재 기능 범위가 욕구를 하회함.
4. 소유감의 조건부 구조: 현재 소유감은 2점이나, 성공 서사 맥락에서는 "원래 내 거였는데"라는 소급 소유감 언어를 사용. 소유감이 미래 성공 서사에 연동됨.
5. 제작자 포지션 자발적 발화: 인터뷰어의 유도 없이 "제작자 입장에서"라는 표현을 스스로 사용. B그룹 창작 성향이 제작자 프레임으로 자연 활성화됨.

## 6. Thematic Analysis (Braun & Clarke 6단계)

### Phase 1~3: 코드 생성 및 초기 테마 도출

코드 클러스터: `육성-핵심동인`, `서사-필수`, `선택행위-인식`, `시간투자-아쉬움`, `제작자-포지션`, `성공서사-소유감전환`, `기능범위-불충분`, `AI아이돌-심리장벽`, `콘텐츠-육성보조`, `추가개입욕구`

### Phase 4~6: 테마 정제

### Theme 1: 육성 서사 욕구가 모든 인식의 핵심 동인

- 관련 코드: `육성-핵심동인`, `성장서사-핵심동인`, `제작자-포지션`, `서사-필수요소`
- 근거 발화: VC-03, VC-04, VC-05, VC-10
- 요약: 조수연의 반응 전체가 육성 서사 욕구를 중심으로 조직된다. 캐스팅 고민은 "잘 키우면 됨"으로 전환되고, 세계관 수정은 "C→A 성장 서사"로 연결되며, 소유감은 "블랙핑크처럼 크면 뿌듯할 것"으로 미래 성공 서사에 연동된다. 팬픽 코어팬 경력(13~23세)이 형성한 서사 제작 성향이 이 서비스에서도 그대로 활성화됨.

### Theme 2: 선택 행위 인식은 존재하나 개별 멤버 애착으로 미전환

- 관련 코드: `선택행위-인식`, `H2-지지`, `아쉬움-시간투자귀인`, `조합단위-애착`, `개별멤버-애착-부재`
- 근거 발화: VC-01, VC-02
- 요약: Q1(5점), Q2(5점)로 선택 행위 인식은 명확하다. 그러나 Q4 아쉬움 4점의 원인이 멤버 개별 감정이 아닌 "투자된 시간 아까움"이고, "한 명씩 사라지는 건 상관없다"는 발언이 공존한다. 선택이 인식되었으나 그 인식이 멤버 개인에 대한 감정 애착으로 발전하지 않은 상태.

### Theme 3: 제작자 포지션의 자발적 활성화

- 관련 코드: `제작자-포지션`, `IP제작-인식`, `H7-지지`, `B그룹-제작자프레임`, `추가개입욕구`
- 근거 발화: VC-08, VC-09, VC-10
- 요약: "제작자 입장에서", "원래 내 거였는데", "딴 거 있으면 더하고 싶음" — 세 발언 모두 인터뷰어 유도 없이 자발적으로 나왔다. B그룹(창작 성향 / AI 헤비유저)의 특성상 세계관 수정이라는 최소 개입만으로도 제작자 프레임이 즉각 활성화됨.

### Theme 4: 소유감의 시제 구조 — 현재 미형성, 미래 성공 조건부

- 관련 코드: `소유감-조건부`, `성공서사-소유감전환`, `소급소유감`, `H4-부분`
- 근거 발화: VC-09, VC-10; 소유감 Q 2점 vs 구체화 욕구 5점
- 요약: 소유감이 현재 시제(2점)와 미래 시제("원래 내 거였는데", "뿌듯할 것")로 분리된다. 현재 기능 범위에서는 소유감이 형성되지 않지만, 성공 서사가 실현되면 소급적으로 소유감이 전환될 것이라는 심리 구조. 소유감을 현재 시제에서 측정하면 저평가됨.

### Theme 5: 콘텐츠 구조 비판 — 콘텐츠 단독으로는 리텐션 불가

- 관련 코드: `콘텐츠-육성보조`, `질림-경고`, `리텐션위험`, `AI아이돌-전제-한계`, `콘텐츠단독-부족`
- 근거 발화: VC-06, VC-07
- 요약: "그것만 기능이 있으면 어느 순간 질려버릴 것임"이라는 직접 경고와 "AI 아이돌이라는 전제로 콘텐츠 소비에 한계"라는 두 발언이 현재 콘텐츠 구조의 리텐션 위험을 지적한다. 콘텐츠는 육성 서사의 사이사이 부산물로 포지셔닝되어야 하며, 콘텐츠가 메인 기능이 될 경우 이탈을 예고함.

## 8. Jobs-to-be-Done (JTBD)

### Job 1 (핵심)

> "내가 캐스팅한 아이돌을 훈련시키고 성장시켜서, 내가 만든 서사를 가진 그룹을 완성하고 싶다."

- Functional: 등급 변화, 훈련 결과, 성장 서사가 시각적으로 반영되는 육성 루프
- Emotional: C→A 성장 순간의 "짜릿함", 성공 시 제작자 자부심("뿌듯할 것")
- Social: 약함 (현재 단계). 그러나 성공 서사 이후 외부 공인 욕구 잠재 ("블랙핑크처럼 크면")

### Job 2 (보조)

> "이 그룹의 세계관과 관계성을 내가 원하는 방향으로 직접 설계하고 싶다."

- Functional: 관계성 설정 외 추가 편집 요소 (훈련 방향, 콘셉트, 개인 서사)
- Emotional: 만드는 행위 자체의 재미 (설정 수정 재미 5점)
- Social: 약함

### Job 3 (잠재)

> "스토리 소비 후 특정 멤버들 간의 비하인드 서사가 궁금할 때, 세계관으로 자연스럽게 이동하고 싶다."

- Functional: 스토리 내 멤버 관계 → 세계관 편집 연결 플로우
- Emotional: "유경-예나 이야기 궁금해, 비하인드 스토리니까" — 호기심 기반 이동
- Social: 없음

### Job 4 (비욕구)

> "콘텐츠를 단독으로 소비하는 것은 원하지 않는다."

- "그것만 기능이 있으면 어느 순간 질려버릴 것임" — 콘텐츠 단독 서비스에 대한 명시적 거부.
- 이것은 "하고 싶지 않은 Job"으로, 콘텐츠형 서비스 단독 포지셔닝이 이 유저에게 무효임을 의미.

## 10. Mental Model Gap Analysis

### Gap 1: 세계관 수정 = 관계성 편집 vs 세계관 수정 = 성장 서사 설계

| 서비스 현재 모델 | 사용자 멘탈 모델 |
|----------------|----------------|
| 세계관 기능 = 멤버 간 관계성 설정 편집 | 세계관 기능 = 성장 서사(등급, 훈련 방향, 멤버 개인 서사)를 내가 설계하는 제작 도구 |
| 관계성 설정이 세계관 개입의 주요 기능 | 관계성 설정 완료 후 "딴 거 있으면 더하고 싶음" — 관계성은 시작점에 불과 |

영향: 현재 세계관 기능의 범위가 이 유저의 제작 욕구를 충족하지 못함. 관계성 설정만으로는 구체화 욕구 5점에 상응하는 경험을 제공할 수 없음. 기능 확장 없이는 욕구 좌절이 이탈로 이어질 가능성.

### Gap 2: 소유감 측정 = 현재 시제 vs 소유감 실제 구조 = 성공 서사 연동

| 서비스/리서치 설계 | 사용자 멘탈 모델 |
|-----------------|----------------|
| 소유감 설문 = 현재 상태 측정 (2점) | 소유감 = 성공 서사 발생 시 소급 활성화 ("원래 내 거였는데") |
| 소유감 낮음 = IP 제작 인식 약함 | 소유감은 미래 투자 의향의 형태로 존재. 현재 측정값이 실제 잠재 소유감을 과소평가. |

영향: 현재 소유감 2점을 IP 제작 인식 부재로 단순 해석하면 오류. 성공 서사(육성 루프 완성, 데뷔 성공)가 구현되면 소유감이 폭발적으로 증가할 가능성. 측정 시점 재설계 필요.

### Gap 3: 콘텐츠 = 서비스 핵심 기능 vs 콘텐츠 = 육성 서사의 부산물

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 콘텐츠(숙소 스토리, 하이라이트)가 재방문 유인 | "육성이 메인이고 사이사이 얘네가 어떤 일들이 있었는지 궁금한 거지" |
| 콘텐츠 제공 = 리텐션 | 콘텐츠 단독으로는 "어느 순간 질려버릴 것" — 육성 루프가 없으면 콘텐츠도 의미 없음 |

영향: 콘텐츠 기능 강화만으로는 이 유저 유형의 리텐션 확보 불가. 콘텐츠가 육성 서사의 맥락 안에 위치할 때만 소비 동기가 발생함. MVP 설계 순서 재고 필요 (육성 루프 → 콘텐츠 순서).

### Gap 4: AI 아이돌 속성 = 서비스 전제 vs AI 아이돌 속성 = 콘텐츠 소비 장벽

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| AI 아이돌이라는 설정이 서비스의 핵심 정체성 | "AI 아이돌이라는 전제가 있다보니 콘텐츠를 보는 것에 한계가 생겨버림" |
| 속성 자체가 매력 요소 | AI 속성이 감정 투입을 억제하는 심리 장벽으로 작용 — 특히 B그룹(비팬) 관점 |

영향: "AI 아이돌" 프레이밍 자체가 비팬/창작 성향 세그먼트의 콘텐츠 소비를 억제할 수 있음. AI 속성이 문제인지 콘텐츠 퀄리티가 문제인지 원인 미분리 상태 — 추가 검증 필요.

## 11. Norman's 7 Stages of Action

### 11.1 Goal (목표)

- 유저 목표: 아이돌을 직접 캐스팅하고 훈련시켜 성공 서사를 완성하는 것. "제작자 입장"에서 IP를 소유하는 것.
- 시스템 목표: 캐스팅 → 그룹 완성 → 세계관 수정 → 콘텐츠 소비 (현재 플로우)

목표 불일치: 시스템은 "완성된 그룹 소비"로 수렴하지만, 유저 목표는 "성장 서사 제작"이다. 현재 플로우가 유저 목표를 지원하지 못함.

### 11.2 Execution Side (실행)

| 단계 | 분석 |
|------|------|
| Plan (계획) | 블라인드 UI 상태에서 남은 후보 중 고민. "결정장애" 귀인이지만 선택 과정 자체는 의미 있게 경험됨. |
| Specify (구체화) | 세계관 수정 시 "C→A 성장 서사", "훈련 방향"까지 구체적 비전 제시. 현재 기능 범위 초과. |
| Perform (수행) | 캐스팅 및 관계성 설정은 완료. 수행 후 즉각 추가 기능 요청 ("딴 거 있으면 더하고 싶음"). |

### 11.3 Evaluation Side (평가)

| 단계 | 분석 |
|------|------|
| Perceive (인지) | 관계성 설정 완료 상태를 인지 → 기능 범위 제한을 즉각 인식 |
| Interpret (해석) | "이것만으로는 부족하다" — 기능 한계로 해석 |
| Compare (비교) | 기대(성장 서사 제작) vs 현실(관계성 설정 편집) — 간극 크게 존재 |

### 11.4 Gulf of Execution (실행의 간극)

- 육성 루프 기능 자체가 존재하지 않아 실행 의도를 수행할 수단이 없음
- "훈련시키고 C→A 성장"이라는 구체적 계획이 있으나 이를 실행할 기능 부재
- 세계관 편집 기능이 관계성 설정에 한정 — 원하는 행위를 수행할 수 없음

### 11.5 Gulf of Evaluation (평가의 간극)

- 소유감 측정 결과(2점)가 잠재 소유감을 반영하지 못하는 구조적 간극
- 현재 서비스 상태에서 "육성이 메인"이라는 기대를 충족받을 수 없음을 인식 → 리텐션 위험 신호
- AI 아이돌 전제로 인한 콘텐츠 소비 한계 — 시스템 출력과 기대 불일치

## 12. Norman's 3 Levels of Design

### 12.1 Visceral Level (본능적 반응)

- 긍정: 블라인드 UI 상태에서 직접 선택하는 경험 (Q1 5점, Q2 5점). 관계성 설정 후 즉각 추가 개입 욕구 표현.
- 부정: 소유감 2점 — 현재 시제에서는 강한 소유 감각이 형성되지 않음. AI 아이돌 전제로 인한 콘텐츠 소비 심리 장벽.
- 시사점: Visceral 레벨에서 선택 경험 자체는 긍정적이나, 콘텐츠 소비 단계에서 AI 아이돌이라는 속성이 심리 장벽으로 작용함. 최초 선택 경험의 긍정성을 유지하면서 AI 속성에 대한 프레이밍 재설계 필요.

### 12.2 Behavioral Level (행동적 반응)

- 긍정: 캐스팅 플로우는 의미 있게 경험 (고민 5점, 선택감 5점). 세계관 수정 완료 후 자발적 추가 개입 요청. "제작자 입장에서" 자발적 발화.
- 부정: 세계관 편집 기능 범위 제한 — 원하는 행위(훈련 방향, 서사 설계)를 수행할 수단 없음. "딴 거 있으면 더하고 싶음" = 기능 한계에서 오는 행동 좌절.
- 시사점: B그룹 창작 성향 유저의 행동 패턴은 최소 개입으로도 강한 제작 행동을 유발한다. 기능 범위 확장이 행동 좌절을 제작 몰입으로 전환하는 핵심 레버.

### 12.3 Reflective Level (반성적 반응)

- 긍정: "제작자 입장에서" 자발적 인식 (VC-10). 세계관 구체화 욕구 5점. 성공 서사에 대한 기대("뿌듯할 것") — 서비스에 대한 장기적 투자 의향 존재.
- 부정: "AI 아이돌이라는 전제로 콘텐츠 소비에 한계" — 서비스 정체성에 대한 Reflective 회의. "육성 없으면 질려버릴 것" — 리텐션에 대한 직접적 부정 예측.
- 시사점: 제작자 포지션 인식(긍정)과 서비스 구조 비판(부정)이 공존. Reflective 레벨에서 이 서비스에 장기적으로 투자할 가치가 있는지에 대한 판단이 아직 유보 상태. 육성 루프 구현 여부가 Reflective 레벨 판단을 결정할 핵심 변수.

## 13. Hypothesis Validation (가설 검증)

### Sprint 1 가설

### H1: 유저는 캐스팅만으로도 애착을 느낀다

| 항목 | 내용 |
|------|------|
| 판정 | 약함 (개별 멤버 애착 미형성) |
| 근거 - 약화 | "한 명씩 사라지는 건 상관없음" 직접 발언. Q4 아쉬움 4점의 이유가 "시간 투자 아까움"이지 멤버 개별 감정이 아님. 멤버 개별 애착 발언 전무. |
| 근거 - 부분 | 조합 단위 아쉬움(4점)은 존재. 투자 시간 기반의 집합적 애착이 발생하나, 이는 개별 멤버 애착과 구분됨. |
| 조건 | 캐스팅만으로는 개별 멤버 애착 발생하지 않음. 조합 단위 + 투자 시간 기반 아쉬움은 존재. |

### H2: 유저는 결과물보다 선택 과정에 의미를 둔다

| 항목 | 내용 |
|------|------|
| 판정 | 확인 (단, 선택보다 육성 과정이 더 강한 동인) |
| 근거 - 지지 | Q2 5점 ("내가 선택했다"). 블라인드 UI 반응. "남은 애들 중에 고민해서 직접 선택했으니까" (VC-01). |
| 근거 - 조건 | 선택 과정 의미 부여는 확인되나, Q3 역문항 3점에서 "랜덤이어도 잘 키우면 됨"으로 육성 과정으로 시선 전환. 선택 과정보다 육성 과정에서 더 강한 의미를 기대함. |
| 조건 | H2는 지지되나, 이 유저의 핵심 의미 부여 대상은 선택 과정이 아닌 육성 과정임. |

### H3: 이메일 입력은 단순 알림이 아니라 기대 행동이다

| 항목 | 내용 |
|------|------|
| 판정 | 모호 (직접 발언 없음) |
| 근거 | 육성 서비스에 대한 기대 발언 반복 ("잘 키우면 됨", "C→A 성장 서사"). 그러나 이메일 전환 행동 또는 발언이 직접 확인되지 않음. |
| 조건 | 육성 루프가 이메일 전환 맥락과 연결된다면 기대 행동으로 작동할 가능성 있으나, 현재 데이터로는 확인 불가. |

### Sprint 2 가설

### H4: 세계관 수정 행동은 애착을 강화한다

| 항목 | 내용 |
|------|------|
| 판정 | 확인 (단, 현재 기능 범위 한계 존재) |

## 15. Cross-Analysis Summary

### 15.1 핵심 인사이트 5선

#### 인사이트 1: 캐스팅은 입장권이고 육성이 핵심 제품이다

조수연의 모든 발화가 육성 서사 욕구를 중심으로 조직된다. 캐스팅 고민(5점)은 "잘 키우면 됨"으로 즉각 전환되고, 세계관 수정은 "C→A 성장 서사"로 확장되며, 성공 예측은 "블랙핑크처럼 크면 뿌듯할 것"으로 귀결된다. 이 유저에게 캐스팅은 서비스의 입장권이고, 육성 루프가 실제 제품이다. 현재 육성 루프가 없는 서비스 구조에서 이 유저의 리텐션을 기대하기 어렵다.

액션: 육성 루프 MVP를 현재 Sprint에서 설계하지 않으면 이 유저 세그먼트의 이탈을 막을 수 없음. 캐스팅 이후 "첫 훈련 결과" 또는 "등급 변화 신호"를 MVP에 포함하는 것을 최우선 과제로 설정.

#### 인사이트 2: 소유감 2점은 저평가다 — 소유감의 시제 구조를 이해해야 한다

소유감 Q 2점을 단순히 소유 의식 부재로 해석하면 오류다. "예나를 데리고 다른 사람이 슈퍼스타가 되면 원래 내 거였는데"라는 발언은 소유감이 미래 성공 서사에 연동된 조건부 구조임을 보여준다. 현재 서비스 상태(육성 루프 없음, 데뷔 상태 유지)에서는 소유감이 형성될 조건이 갖춰지지 않은 것이지, 소유 의지 자체가 없는 것이 아니다. 소유감 측정을 육성 루프 완성 이후 재측정해야 실제 소유 감각을 포착할 수 있다.

액션: 소유감 측정 시점을 육성 이벤트(첫 훈련 완료, 등급 상승, 첫 활동 결과) 이후로 재설계. 현재 시제 소유감 단독 측정은 이 유저 유형에서 과소평가 구조임을 팀 내 공유.

#### 인사이트 3: B그룹(창작 성향)에서 제작자 포지션이 자발적으로 활성화된다

"제작자 입장에서"라는 표현이 인터뷰어 유도 없이 자발적으로 나왔다. 생성형 AI 헤비유저이자 팬픽 코어팬인 조수연에게는 세계관 수정이라는 최소 개입만으로도 제작자 프레임이 즉각 활성화된다. 이는 B그룹(창작 성향 / AI 활용자) 세그먼트에서 IP 제작 인식이 강하게 작동할 것임을 시사한다. H7의 B그룹 특이적 확인.

액션: 제작자 포지션 프레이밍을 B그룹 타깃 핵심 메시지로 활용. "당신이 이 그룹의 프로듀서입니다"라는 프레이밍이 B그룹에서 높은 효과를 보일 가능성. A그룹(팬 성향)에서의 동일 효과는 별도 검증 필요.

#### 인사이트 4: 콘텐츠 단독 구조는 이 유저 세그먼트에게 리텐션 실패 구조다

"그것만 기능이 있으면 어느 순간 질려버릴 것임"은 현재 서비스 구조에 대한 직접적 이탈 경고다. 콘텐츠(숙소 스토리, 하이라이트)가 육성 서사의 맥락 밖에 위치할 때 소비 동기가 발생하지 않는다. AI 아이돌이라는 전제가 추가로 콘텐츠 소비의 심리적 한계를 만든다. 이 두 요인이 결합되면 콘텐츠 소비형 서비스 포지셔닝은 B그룹에서 작동하지 않는다.

액션: 콘텐츠 기능은 육성 루프 내에 위치시키는 설계 원칙 수립. "훈련 중 멤버의 일상 스토리", "등급 상승 기념 하이라이트" 등 육성 맥락에 종속된 콘텐츠 포지셔닝으로 전환.

#### 인사이트 5: 멤버 개별 서사 부재가 개별 애착 형성의 구조적 장벽이다

"서사 없으면 사라져도 잘 모름"이라는 발언은 현재 서비스의 멤버 개별 서사 부재를 직접 지적한다. Sprint 1에서 H1(캐스팅만으로 애착)이 약하게 나타나는 이유가 캐스팅 UI 설계의 문제가 아니라 캐스팅 이후 멤버별 서사가 없는 것과 연결될 가능성이 크다. Sprint 2에서 "유경-예나 이야기 궁금해"라는 발언이 등장하는 것은 멤버 간 관계 서사가 제공될 때 개별 멤버 애착이 생성될 수 있음을 시사한다.

액션: 멤버별 최소 서사 라인(개인 서사 1개, 멤버 간 관계 에피소드 1개)을 MVP에 포함하는 것이 H1 재검증 및 개별 멤버 애착 형성의 선행 조건. "예나" 중심 발언이 Sprint 2 전반에 등장한다는 점에서 특정 멤버 서사 강화가 소유감 전환에 효과적일 가능성.
