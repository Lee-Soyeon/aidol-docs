## 3. Behavioral Sequence Analysis

### 3.1 이정인 (U12) 행동 시퀀스

```
서비스 진입
→ 연습생 리스트 화면 진입
→ 계약완료(모자이크) 캐릭터 리스트 상단 노출 확인
→ "계약 완료 의미는 알겠는데" → 의미 파악 시도
→ "왜 앞에 있는지 모르겠음" → 구조 혼란
→ 필터 기능 부재 인지 → 개선 요청 발화
→ "남은 캐스팅 슬롯" 문구 확인 → 의미 파악 실패
→ 캐스팅 인원 규칙 탐색 → 설명 부재 인지
→ 등급 체계 탐색 → "설명이 부족함" 직접 언급
→ 캐스팅 진행 (세부 행동 불명)
→ 캐스팅 보드 탐색
→ 캐스팅 보드에서 캐스팅 화면으로 이동 버튼 부재 인지
→ 다른 연습생 캐스팅 버튼 부재 인지
→ 그룹 엠블럼 생성 시도
→ "그룹 엠블럼 로고만 생성되도록" 요청 → 로고 외 이미지 출력 문제 발견
→ 심층 인터뷰 (정량 응답)
→ 제작 인식 4점 / 발전 의향 2점 / 소유감 2점 / 아쉬움 1점 응답
```

### 3.2 행동 패턴 요약

1. 온보딩 부재로 인한 반복 탐색: 등급, 캐스팅 인원, 슬롯 의미 등 기본 규칙을 서비스 자체에서 파악하려 시도하나 정보 없음.
2. 구조적 혼란 → 즉각적 개선 요청: 혼란 상황마다 "있었으면 좋겠음" 형태의 구체적 UX 개선 요청으로 발화. 감정 반응보다 분석적 피드백이 지배.
3. 탐색 흐름 단절: 캐스팅 보드 → 다른 연습생 캐스팅으로의 동선이 없어 흐름이 끊김.
4. 정량 점수 분리: 제작 인식(4점)은 높으나 발전 의향(2점), 소유감(2점), 아쉬움(1점)은 낮음 → 제작 행위와 감정적 몰입이 분리된 상태.
5. 후기 전체가 UX 개선 요청으로 구성: 감정적 반응이 부재하고 분석/비판 모드로 일관.

시간축 기반 감정 곡선 (5단계: 매우 부정 ~ 매우 긍정).


### 4.1 감정 곡선 요약

- 최저점: 아쉬움 1점 (전체 유저 최저). 캐스팅 과정 전반에 걸쳐 감정 레벨이 2~3 사이에 머물며 상승 구간이 없음.
- 유일한 긍정 신호: 제작 인식 4점. 그러나 이것이 발전 의향이나 소유감으로 연결되지 않음.
- 패턴: 감정 기복 없이 분석 모드 유지. 혼란 → 개선 요청으로 곧바로 전환. 몰입이 아닌 평가 모드가 지배적.
- 특이점: B그룹(AI 활용자) 특성상 서비스를 체험 대상이 아닌 평가 대상으로 접근. 감정 반응 자체가 억제되어 있을 가능성.

## 6. Thematic Analysis (Braun & Clarke 6단계)

### 단계 1-2: 친숙화 및 초기 코드 생성

초기 코드 목록:
- 온보딩부재, 규칙이해실패, 용어이해실패, 등급설명부재
- 정보구조혼재, 모자이크상단노출, 필터부재
- 네비게이션단절, 캐스팅보드동선없음
- 제작인식4점, 발전의향2점, 소유감2점, 아쉬움1점
- 엠블럼로고외이미지, 기능범위문제
- 감정반응부재, UX개선요청지배

### 단계 3-4: 테마 탐색 및 검토

### Theme 1: 온보딩 부재가 선택 행위 인지 자체를 차단

- 관련 코드: `온보딩부재`, `규칙이해실패`, `용어이해실패`, `등급설명부재`, `캐스팅목적불명`
- 근거: VC-03, VC-04, VC-05
- 요약: "남은 캐스팅 슬롯" 문구 이해 실패, 여러 명 캐스팅해야 한다는 규칙 부재, 등급 체계 설명 부재 등 세 개의 독립적 이해 실패가 동시에 발생. 이는 캐스팅 행위가 '선택'으로 인지되기 전에 '탐색 과제'가 되어버림을 의미. U10(jhlee)에서도 동일 패턴 관찰됨으로써 반복 이슈 확인.

### Theme 2: 정보 구조 설계 실패가 탐색 비용을 증가시킴

- 관련 코드: `정보구조혼재`, `모자이크상단노출`, `필터부재`, `선택가능불가능구분실패`
- 근거: VC-01, VC-02
- 요약: 계약완료(선택 불가) 캐릭터가 리스트 상단에 모자이크 처리된 채 노출됨. 피실험자는 의미는 이해하지만 왜 앞에 있는지 납득하지 못함. 필터 기능 부재로 직접 탐색 비용 증가. U5(차유경), U10(jhlee)에서도 동일 이슈.

### Theme 3: 네비게이션 단절이 탐색 플로우를 끊음

- 관련 코드: `네비게이션단절`, `캐스팅보드동선없음`, `탐색흐름단절`
- 근거: 행동 관찰 (캐스팅 보드 탐색 구간)
- 요약: 캐스팅 보드에서 캐스팅 화면으로 이동하거나 다른 연습생을 캐스팅하는 CTA가 없음. 목표 달성을 위한 다음 단계가 UI에 제공되지 않아 흐름이 자연스럽게 이어지지 않음.

### Theme 4: 제작 인식과 감정적 몰입의 분리

- 관련 코드: `제작인식4점`, `발전의향2점`, `소유감2점`, `아쉬움1점`, `감정반응부재`
- 근거: 정량 지표 (섹션 5, 섹션 6)
- 요약: 제작 인식 4점은 'AI 활용자' 세그먼트에서 의미 있는 신호. 그러나 발전 의향 2점, 소유감 2점, 아쉬움 1점으로 제작 인식이 지속적 관여나 소유 욕구로 전환되지 않음. 'AI로 만들었다'는 인식과 '이 캐릭터에 감정을 투자하겠다'는 의사가 분리된 상태.

### Theme 5: AI 활용자 시각의 기능 품질 비판

- 관련 코드: `엠블럼로고외이미지`, `기능범위문제`
- 근거: 행동 관찰 (그룹 엠블럼 생성)
- 요약: ML engineer로서 생성 AI 결과물에 대한 높은 기대치와 비판적 시각. 엠블럼 생성 시 로고 외 이미지가 출력되는 점을 즉각적으로 기능 범위 문제로 인지하고 개선 요청. 다른 세그먼트보다 기술적 정확성에 민감.

### 단계 5-6: 테마 확정 및 보고서 작성

5개 테마 확정: Theme 1(온보딩 차단), Theme 2(정보 구조 실패), Theme 3(네비게이션 단절), Theme 4(제작-감정 분리), Theme 5(AI 품질 비판).

## 10. Mental Model Gap Analysis

사용자의 멘탈 모델과 서비스의 실제 모델 간 차이 분석.

### Gap 1: 리스트 = 선택 가능 항목 vs 리스트 = 선택 가능 + 불가능 혼재

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 전체 연습생 표시 (계약완료 포함) | 리스트에는 선택 가능한 항목만 있어야 함 |
| 계약완료 상태를 모자이크로 표시 | 선택 불가 항목이 앞에 있으면 안 됨 |

영향: 리스트 진입 즉시 혼란 발생. "왜 앞에 있는지 모르겠음"이라는 직접 발화. 탐색 비용 증가 → 선택 행위 시작 전에 이미 인지적 부담 누적.

### Gap 2: "남은 캐스팅 슬롯" = 직관적 진행 상태 표시 vs 사용자에게 의미 불명

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| "남은 캐스팅 슬롯"으로 진행 상태 안내 | 해당 문구의 의미를 파악하지 못함 |
| 숫자/문구로 상태 표시 | 맥락 없이 등장한 용어는 이해 불가 |

영향: 현재 캐스팅 진행 상태를 파악하지 못함 → 얼마나 더 해야 하는지 모름 → 목표 지점 불명확. H2(선택 과정에 의미 부여) 차단.

### Gap 3: 캐스팅 = 그룹 구성 행위 vs 사용자에게 캐스팅 목적 불명

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 여러 명을 캐스팅하여 그룹 구성 | "여러 명 해야 한다는 설명이 없음" |
| 구조 자체로 암시적 안내 | 구조를 이해하기 전에 규칙 명시 필요 |

영향: 캐스팅의 목적(그룹 구성)을 이해하지 못한 채 진행 → 각 선택 행위가 전체 맥락에서 어떤 의미인지 모름 → H1(캐스팅으로 애착 발생) 전제 조건 미충족.

### Gap 4: 캐스팅 보드 = 완성 상태 확인 vs 사용자에게 다음 동선 없음

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 캐스팅 보드에서 결과 확인 | 캐스팅 보드 → 캐스팅 화면으로 다시 돌아가고 싶음 |
| 명확한 탐색 동선 미설계 | 다음 단계가 무엇인지 UI에서 파악 불가 |

영향: 탐색 플로우 단절 → 추가 캐스팅 의사가 있어도 진행 불가 → 전체 경험 흐름 단절.

### Gap 5: 제작 인식 = 감정적 몰입으로 연결 vs 제작 인식이 몰입으로 전환되지 않음

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 직접 선택/생성 → 소유감/애착 발생 | 만들었다는 인식은 있으나 이게 '내 것'이라는 감각 없음 |
| 제작 행위 → 지속 관여 유도 | 팬덤 맥락 없이 캐릭터에 감정 투자 근거 없음 |

영향: 제작 인식 4점이라는 긍정 신호가 발전 의향 2점, 소유감 2점으로 이어지지 않음. '만들기'와 '키우고 싶다/내 것이다'의 감정 경로가 분리.

## 11. Norman's 7 Stages of Action Analysis

### 11.1 Goal (목표)

- 유저 목표: 연습생을 탐색하고 선택하여 그룹을 구성하기 (규칙 이해 후)
- 시스템 목표: 연습생 캐스팅 → 그룹 구성 → 결과 확인

### 11.2 Execution Side (실행)

| 단계 | 분석 |
|------|------|
| Plan (계획) | 계획 수립 전 단계에서 이미 규칙을 이해하지 못함 → 목표 자체가 불명확한 상태 |
| Specify (구체화) | 어떤 기준으로 선택해야 하는지 불명확 (등급 의미 모름, 인원 목표치 모름) |
| Perform (수행) | 캐스팅 자체는 물리적으로 수행 가능. 그러나 의미 없이 진행되는 상태. 캐스팅 보드 → 캐스팅 화면 이동 불가 |

### 11.3 Evaluation Side (평가)

| 단계 | 분석 |
|------|------|
| Perceive (인지) | 결과 화면 확인 가능. 엠블럼 생성 결과 인지 가능. |
| Interpret (해석) | "계약 완료 의미는 알겠는데" → 개별 요소는 해석하나 전체 구조는 이해 못함. 엠블럼에 로고 외 이미지가 나옴 → 기능 범위 오작동으로 해석 |
| Compare (비교) | 기대(로고만 생성) vs 결과(로고 외 이미지) → 괴리. 기대(명확한 규칙/온보딩) vs 결과(온보딩 부재) → 괴리 |

### 11.4 Gulf of Execution (실행의 간극)

- 온보딩이 없어 어떤 규칙으로 무엇을 해야 하는지 불명확
- "남은 캐스팅 슬롯" 등 UI 용어가 직관적이지 않아 현재 상태 파악 불가
- 캐스팅 보드에서 캐스팅 화면으로 돌아가는 방법이 없음

### 11.5 Gulf of Evaluation (평가의 간극)

- 전체 과정에서 "지금 올바르게 진행하고 있는가"에 대한 피드백이 부재
- 엠블럼 생성 결과물이 의도와 다를 때 수정/재시도 방법 불명확
- 캐스팅 완료 후 "무엇이 완성됐는지"에 대한 명확한 완료 상태 인지 어려움

## 12. Norman's 3 Levels of Design

### 12.1 Visceral Level (본능적 반응)

- 발화 근거 부족: 원본 분석 요약에서 첫인상에 대한 감정적 발화가 추출되지 않음.
- 관찰 추론: B그룹(비팬) 특성상 아이돌 캐릭터의 시각적 매력에 대한 즉각적 감정 반응이 낮거나 없을 가능성. U5(최지윤, 팬 성향)가 "잘생겨서 다행이네요"라고 첫인상에 즉각 반응한 것과 대조됨.
- 모자이크 캐릭터 혼재 노출에 대해 "왜 앞에 있는지 모르겠음"이라는 반응 → 시각적 혼란이 Visceral Level의 첫 반응.

### 12.2 Behavioral Level (행동적 반응)

- 부정: 온보딩 부재로 어떻게 행동해야 하는지 모름 → 탐색 행동 반복
- 부정: "남은 캐스팅 슬롯" 문구 → 현재 상태 파악을 위한 UI 인터랙션 실패
- 부정: 캐스팅 보드 → 캐스팅 화면 이동 버튼 없음 → 목표 달성 위한 행동 수행 불가
- 부정: 엠블럼 생성 시 로고 외 이미지 출력 → 의도와 다른 결과
- 시사점: Behavioral Level 전반에서 마찰이 집중되어 있음. 핵심 플로우(연습생 탐색 → 선택 → 그룹 구성)의 각 단계에서 인터랙션 모델이 사용자 예상과 불일치.

### 12.3 Reflective Level (반성적 반응)

- 관찰: 모든 발화가 UX 개선 요청. 반성적 의미 부여 발화(예: "국프 같은 느낌", "내 새끼" 등)가 없음.
- 유일한 반성적 신호: "K-pop 외국팬들이 콘텐츠 생성 요소들을 좋아할 것 같다" → 자신이 아닌 타인을 통해 서비스 가치를 반성적으로 평가. 직접적 감정 몰입이 아닌 메타 관찰 수준.
- 시사점: Reflective Level에서 자신의 경험에 의미를 부여하는 과정이 발생하지 않음. 비팬 + 온보딩 부재의 조합이 감정적 의미 형성을 차단. 서비스 가치는 타인(K-pop 외국팬)에게 있을 것으로 외재화.

## 13. Hypothesis Validation (가설 검증)

### H1: 유저는 캐스팅만으로도 애착을 느낀다

| 판정 | 반대 (강함) |
|------|-----------|
| 근거 - 반대 | 아쉬움 1점 (전체 유저 최저). 소유감 2점. 후기 전체가 UX 개선 요청으로 구성 → 감정적 반응 부재. |
| 근거 - 부분 지지 | 제작 인식 4점. 단, 이것이 애착이 아닌 'AI 기술 체험' 인식일 가능성 높음. |
| 구조적 원인 1 | 온보딩 부재로 캐스팅 행위가 '선택'이 아닌 '탐색 과제'가 되어버림 → H1의 전제 조건 미충족 |
| 구조적 원인 2 | 비팬 세그먼트 → 캐릭터에 감정 투자할 팬덤 맥락 부재 → 애착 형성의 문화적 기반 없음 |
| 결론 | 현재 조건에서 캐스팅만으로 애착 발생은 불가. 온보딩 개선 후에도 비팬 세그먼트에서 H1이 성립하는지 별도 검증 필요. |

### H2: 유저는 결과물보다 선택 과정에 의미를 둔다

| 판정 | 검증 불가 (전제 조건 미충족) |
|------|--------------------------|
| 근거 | "남은 캐스팅 슬롯 무슨 의미인지 몰랐음" (VC-03), "여러 명 해야 한다는 설명 없음" (VC-04) → 선택 과정 자체의 인지가 차단됨. 선택 행위에 의미를 부여하려면 먼저 선택 행위를 수행할 수 있어야 함. |
| 내가 선택했다 점수 | 3점 (온보딩 부재로 선택 과정 인지 약화 상태에서의 3점) |
| 결론 | H2는 온보딩이 성공한 조건에서만 의미 있는 검증이 가능. 현재는 H2를 검증할 조건 자체가 충족되지 않음. |

### H3: 이메일 입력은 단순 알림이 아니라 기대 행동이다

| 판정 | 반대 (추정) |
|------|-----------|
| 근거 | 원본 분석 요약에서 이메일 관련 직접 발화 없음. 그러나 아쉬움 1점, 발전 의향 2점 등 후속 콘텐츠에 대한 기대가 전반적으로 없음을 감안하면 이메일 전환이 발생했을 가능성 매우 낮음. |
| 추정 | 비팬 + 온보딩 부재 + 애착 미형성의 조합에서 이메일 전환 동기가 발생할 구조적 근거 없음. |

### 온보딩 vs 본질 구분 가능성

현재 이정인의 낮은 점수들(아쉬움 1점, 소유감 2점, 발전 의향 2점)이 다음 중 어느 것에 기인하는지 분리 불가:
1. 온보딩 실패로 인한 일시적 결과 (온보딩 개선 시 호전 가능)
2. 비팬 세그먼트의 구조적 특성 (온보딩과 무관하게 팬덤 기반 애착 미형성)
3. 캐스팅 자체의 한계 (어떤 조건에서도 캐스팅만으로 애착 불가)

B그룹(비팬)에서 H1이 성립하려면 팬덤 맥락 없이도 캐릭터에 감정 투자가 가능한 별도의 가치 제안이 필요할 수 있음.

## 15. Cross-Analysis Summary

### 15.1 핵심 인사이트 4선

1. 온보딩 부재가 H1/H2 검증의 전제 조건을 붕괴시킴

온보딩이 없어 캐스팅 행위가 "선택"이 아닌 "탐색 과제"가 됨. 선택 행위 인지가 없으면 H1(캐스팅으로 애착)과 H2(선택 과정에 의미 부여) 모두 검증 불가 상태. U10(jhlee)에서도 동일 패턴. 이는 개별 사용자의 특성이 아닌 서비스 구조의 반복 실패.

2. 비팬 세그먼트에서 제작 인식과 감정 몰입은 분리됨

제작 인식 4점은 B그룹의 중요한 긍정 신호이나 발전 의향 2점, 소유감 2점으로 이어지지 않음. 이는 "AI로 무언가를 만들었다"는 기술적 인식과 "이 캐릭터가 내 것이다"라는 팬덤 기반 감정이 다른 경로임을 시사. B그룹에서 제작 인식을 소유감으로 전환하려면 팬덤 맥락이 아닌 다른 동기 설계가 필요.

3. 계약완료 캐릭터 상단 노출은 반복 관찰된 구조적 이슈

U5(차유경), U7(최지윤), U10(jhlee), U12(이정인) 4명에서 동일 이슈. 단순 UX 불편이 아니라 캐스팅 탐색의 첫 진입점에서 혼란을 유발하여 이후 선택 행위 전체에 영향. 최우선 수정 항목.

4. B그룹은 서비스를 체험 대상이 아닌 평가 대상으로 접근

이정인의 모든 발화가 UX 개선 요청으로 구성됨. 서비스를 경험하면서 동시에 평가하는 이중 역할 수행. 이는 B그룹(AI 활용자, 비팬)의 세그먼트 특성으로, 감정 반응보다 기능 분석이 지배적. 이 세그먼트에서 H1을 성립시키려면 팬덤 외 다른 감정 투자 경로(예: AI 기술 몰입, 창작 성취감)가 필요.
