## 3. Emotional Journey

### 3.1 감정 변화 추적

| 구간 | 감정 수준 | 감정 라벨 | 근거 |
|------|---------|----------|------|
| 캐스팅 시작 | + | 탐색적 관심 | 얼굴/포지션 전략적 탐색 시작 |
| 인원 제한 확인 | - | 제약에 대한 아쉬움 | V008: 더 많은 인원 원함 |
| 그룹 콘셉트 설정 | ++ | 강한 역할 몰입 | V001, V002: 사장/기획자 인식 |
| 결과 카드 확인 | ++ | 소장/공유 욕구 | V003, V006: 캡처하고 싶다 |
| 데뷔 이후 콘텐츠 부재 인식 | - | 기대 미충족 | V005: 콘텐츠가 있어야 성공 |

### 3.2 감정 전환점

- **긍정 피크**: 그룹 콘셉트 설정 단계 - "비즈니스 성격은 내가 만든다" (V002) + 결과 카드 확인 시 소장 욕구 (V003)
- **부정 전환**: 연습생 단계 완료 후 데뷔/활동 콘텐츠 부재 인식 - V005, V013

### 3.3 Peak-End 분석

- **Peak**: 그룹 콘셉트 설정 구간 - 기획자 역할 몰입 (++) + 결과 카드 소장 욕구 (++)
- **End**: 데뷔 이후 홍보/활동 콘텐츠 부재에 대한 아쉬움 (-)
- [해석] Peak-End Rule 관점에서, 긍정 Peak는 강하나 End가 부정적이면 전체 경험 기억에 불리하게 작용할 수 있음. 데뷔 이후 콘텐츠의 부재가 결제 전환의 핵심 장벽임을 시사.
