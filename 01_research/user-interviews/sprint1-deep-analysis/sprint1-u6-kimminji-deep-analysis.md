## 3. Behavioral Sequence Analysis

### 3.1 김민지 (U6) 행동 시퀀스

원본 타임스탬프 접근 불가. Summary에서 추정한 행동 흐름:

```
서비스 접속
→ AI 연습생 캐스팅 화면 진입
→ 기존 프리셋 연습생 탐색
→ 가능한 멤버 우선 선택 (캐스팅 가능한 연습생 중 선택)
→ 직접 생성 시도
→ 속도/완성도 문제 인지 → 직접 생성 이탈
→ 얼굴 퀄리티 불만 인지
→ 능력치(육각형) 중심으로 판단 (MBTI는 참고만)
→ 얼굴 + 실력 밸런스 고려한 최종 선택
→ 그룹 콘셉트 설정: 보이그룹 선택
→ 실력/칼각 중심 콘셉트 결정 (케미보다 실력 강조)
→ 결과 카드 확인
→ "내가 키우는 내 아이라는 생각이 들었다" (정서적 동일시)
→ 공유 의향 표명
→ 홍보 전략 사고 ("내가 홍보한다", 라디오 돌리기 등)
→ 경연/스탯 성장 기대 표명
→ 이메일 입력 (직접 데이터 없음)
→ 장기 육성형 서사 기대 발화
```

### 3.2 행동 패턴 요약

1. **실력 중심 선택**: MBTI는 참고만, 능력치가 핵심 판단 기준. 얼굴+실력 밸런스를 전략적으로 고려.
2. **직접 생성 이탈**: 기술적 장벽(속도, 완성도)으로 직접 생성 포기 → 프리셋 선택으로 전환.
3. **PD 행위로 캐스팅 인식**: 단순 클릭이 아닌 기획/육성 행위로 경험. "PD 역할을 했다"는 명시적 역할 인식.
4. **정서적 동일시 발생**: "내 아이" 발화 → 초기 애착 형성 신호.
5. **전략적 팬덤 사고**: 라디오 돌리기 등 실제 팬덤 활동 전략을 서비스 내 그룹에 투영.
6. **결과보다 육성 서사 기대**: 단발 그룹 생성보다 경연/성장 시스템에 관심. 장기 육성 관점 존재.
7. **능력치 재확인 UX 요구**: 포지션 설정 등 후속 단계에서 능력치를 다시 볼 수 있어야 한다는 UX 피드백.

### Theme 1: PD 정체성 투영 - 캐스팅을 기획 행위로 인식

- 관련 코드: `역할인식-PD`, `기획행위-인지`, `선택행위-인식`
- 근거: VC-01 ("PD 역할을 했다"), VC-05 (능력치 중심 판단)
- 요약: 캐스팅을 단순 클릭이 아닌 명확한 기획/육성 행위로 인식. MBTI는 참고만 하고 능력치를 핵심 기준으로 사용하는 것은 프로듀서적 사고방식과 일치. H1의 "선택 행위 인지" 측면에서 강하게 지지.

### Theme 2: 초기 애착 형성과 팬덤 행동 투영

- 관련 코드: `애착초기-형성`, `동일시`, `육성-감정`, `홍보의지`, `전략적사고`, `팬덤지식-적용`, `음원전략`, `공유의향`
- 근거: VC-02 ("내가 키우는 내 아이"), VC-03 ("내가 홍보한다"), VC-04 (라디오 돌리기)
- 요약: "내 아이" 발화는 정서적 동일시 신호. 더 나아가 실제 팬덤 활동(라디오 돌리기 등)을 서비스 내 아이돌에게 투영하는 단계까지 진전. 단순 체험을 넘어 팬 활동 시뮬레이션으로 경험.

### Theme 3: 실력 중심 소비 성향의 일관성

- 관련 코드: `선택기준-능력치`, `MBTI-부차적`, `실력중심소비`, `콘셉트-실력중심`, `칼각선호`, `선택기준-밸런스`
- 근거: VC-05 (MBTI 참고만, 핵심은 능력치), VC-06 (얼굴+실력 밸런스), VC-10 (케미보다 실력/칼각)
- 요약: 캐스팅부터 콘셉트 설정까지 실력 중심 판단이 일관되게 유지. 데이식스 팬(실력파 밴드) + 디자이너 직업(품질 민감)의 배경이 서비스 내 소비 패턴에 그대로 반영.

### Theme 4: 기술적 장벽과 퀄리티 불만

- 관련 코드: `직접생성-이탈`, `속도불만`, `완성도불만`, `UX-장벽`, `프리셋불만-외모`, `UI-정보접근성`, `능력치재확인`
- 근거: VC-07 (직접 생성 이탈), VC-08 (얼굴 퀄리티 불만), VC-09 (능력치 재확인 UI 필요)
- 요약: 직접 생성의 기술적 장벽(속도, 완성도)이 창작 욕구를 차단. 프리셋 퀄리티도 기준에 미달. 능력치 정보의 접근성 문제는 U5(최지윤)의 동일 불만과 패턴 일치.

### Theme 5: 육성 서사에 대한 강한 기대

- 관련 코드: `경연기대`, `스탯성장기대`, `육성서사-기대`, `장기육성-관점`, `리텐션신호`, `리텐션잠재력`
- 근거: VC-12 (경연/스탯 성장 기대), VC-13 (장기 육성 관점), summary 2.2~2.3
- 요약: 현재 서비스의 단발 그룹 생성보다 경연/스탯 성장/장기 육성 시스템에 강한 관심. 이메일 전환도 장기 육성형 구조일 경우 긍정적. "초기 애착 형성"(Theme 2)의 지속성은 육성 서사의 유무에 달려 있음.

### 단계 6: 보고서 작성

5개 테마 확정. 상세 내용은 이하 섹션에서 활용.

## 10. Mental Model Gap Analysis

### Gap 1: 직접 생성 = 창작 경험 vs 직접 생성 = 기술 장벽

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 직접 생성으로 완전 커스텀 아이돌 제작 가능 | 해보고 싶지만 속도/완성도가 기대 이하 → 즉시 이탈 |
| 창작 자유도 제공 | 마찰 임계값이 낮아 빠르게 대안(프리셋)으로 전환 |

**영향**: 창작 욕구는 있으나 기술적 마찰 한 번에 포기. 직접 생성이 핵심 차별화 포인트라면, UX 마찰 제거가 선결 과제. 속도와 완성도가 보장되지 않으면 이 유저 유형은 프리셋으로 즉시 우회.

### Gap 2: 캐스팅 완료 = 시작 vs 캐스팅 완료 = 애착 형성 완료이나 육성 고리 없음

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 캐스팅 → 결과 카드 → 이메일 입력 → 후속 콘텐츠 | 캐스팅 완료 후 "내 아이" 감정은 생겼으나, 다음에 무엇이 있는지 불명확 |
| 이메일로 후속 서사 연결 | 장기 육성형 서비스라면 연결 가능, 단발 콘텐츠라면 전환 약함 |

**영향**: U5와 달리 애착 초기 형성은 성공했으나, 그 애착을 지속시킬 육성 서사가 없으면 이탈. "내 아이" 감정은 켜졌으나, 서비스가 이를 받아줄 구조가 부재.

### Gap 3: MBTI = 개성 지표 vs MBTI = 부차적 참고 정보

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| MBTI를 캐릭터 개성으로 제시 | MBTI는 참고만, 핵심은 능력치 |
| MBTI로 차별화 | 능력치(육각형)가 주 판단 기준 |

**영향**: 실력 중심 소비 유저에게 MBTI 중심 캐릭터 설계는 설득력 약함. 능력치가 전면에 드러나야 하는 구조적 이유 확인.

### Gap 4: 결과 카드 = 완성 확인 vs 결과 카드 = 홍보 출발점

| 서비스 모델 | 사용자 멘탈 모델 |
|------------|----------------|
| 결과 카드는 그룹 완성의 마무리 화면 | "내가 홍보한다" → 결과 카드를 홍보 콘텐츠의 시작으로 인식 |
| 결과 공유 기능 | 홍보 전략(라디오 돌리기) 수준의 능동적 팬 활동 기대 |

**영향**: 결과 카드에 팬덤 활동 연계 기능(공유 최적화, 스트리밍 링크, 응원 투표 등)이 없으면 이 유저의 능동적 에너지를 흡수하지 못함.

## 11. Norman's 7 Stages of Action Analysis

### 11.1 Goal (목표)

- **유저 목표**: 실력과 외모의 균형을 갖춘 보이그룹을 전략적으로 구성하고, 그 성장을 지켜보는 것
- **시스템 목표**: AI 연습생 캐스팅 → 그룹 콘셉트 설정 → 결과 카드 확인 → 이메일 입력

### 11.2 Execution Side (실행)

| 단계 | 분석 |
|------|------|
| Plan (계획) | 보이그룹 선택, 실력/칼각 콘셉트, 능력치 중심 판단 → 명확한 전략 수립 |
| Specify (구체화) | 얼굴+실력 밸런스를 의식적으로 고려하여 선택 기준 구체화. 단, 직접 생성 시도는 기술 장벽으로 중단 |
| Perform (수행) | 프리셋 선택은 원활. 문제 1: 직접 생성 속도/완성도 → 이탈. 문제 2: 능력치 재확인 UI 부재 → 이후 단계에서 선택 근거 확인 불가 |

### 11.3 Evaluation Side (평가)

| 단계 | 분석 |
|------|------|
| Perceive (인지) | 결과 카드 확인 가능. "내 아이" 인식 형성. |
| Interpret (해석) | 결과물을 홍보 출발점으로 해석 ("내가 홍보한다"). 긍정적 해석이나, 경연/성장 고리가 없다는 것도 인지. |
| Compare (비교) | 기대(경연/성장 시스템 있는 육성 서비스) vs 현실(단발 그룹 생성 체험) → 기대와 현실의 간극 존재 |

### 11.4 Gulf of Execution (실행의 간극)

- 직접 생성 기능의 속도/완성도가 유저 기대에 미달 → 창작 행위 진입 불가
- 능력치 재확인 UI 부재 → 포지션 설정 등 후속 단계에서 합리적 판단 어려움
- 얼굴 퀄리티가 아이돌 기준에 미달 → 비주얼 민감 유저(디자이너)에게 첫 관문 마찰

### 11.5 Gulf of Evaluation (평가의 간극)

- 서비스가 경연/스탯 성장 시스템을 제공하지 않는다는 것을 인지 → 현재 서비스로는 장기 몰입 불가 예측
- 이메일 입력 이후 어떤 경험이 제공되는지 불명확 → "장기 육성형이라면 전환 가능"이라는 조건부 기대

## 12. Norman's 3 Levels of Design

### 12.1 Visceral Level (본능적 반응)

- **부정**: 얼굴 퀄리티 불만 → 아이돌 서비스임에도 비주얼 기준 미달 프리셋 존재. 디자이너 직업 특성상 시각적 품질 판단 기준이 높음.
- **부정**: 직접 생성 속도/완성도 문제 → 기대했던 창작 경험이 기술 장벽으로 즉시 차단.
- **시사점**: Visceral Level에서의 비주얼 품질이 이 유저 유형에게는 특히 중요. 디자이너 배경의 유저는 시각적 완성도 기준이 일반 유저보다 높음.

### 12.2 Behavioral Level (행동적 반응)

- **긍정**: 캐스팅 플로우 자체는 이해 가능하고 전략적으로 수행.
- **긍정**: 능력치 정보가 제공될 때 유저가 이를 적극 활용하여 의미 있는 선택 수행.
- **불만**: 능력치 재확인 UI 부재 → 후속 단계에서 정보 접근 불가 (U5와 동일 패턴).
- **불만**: 직접 생성 UX가 완성도 면에서 기대 미달 → 핵심 기능 이탈.
- **시사점**: 실력 중심 유저에게 능력치 정보의 지속적 접근성이 핵심 UX 요소. 포지션 설정 등 모든 단계에서 능력치를 참조할 수 있어야 함.

### 12.3 Reflective Level (반성적 반응)

- **강한 긍정**: "PD 역할을 했다" → 서비스를 통해 의미 있는 역할 정체성 경험.
- **강한 긍정**: "내가 키우는 내 아이" → 캐스팅 후 정서적 동일시 형성. U5(최지윤)의 "퍼즐 끼워 맞추기"와 대조적으로 실제 주체적 선택 경험.
- **부정**: 경연/성장 시스템 부재 인지 → 현재 서비스로는 장기 몰입 한계 자각.
- **시사점**: Reflective Level에서 U6는 U5보다 긍정적 경험을 했음. "내 아이" 발화는 PD 역할 내면화 + 능력치 기반 전략적 선택이 결합된 결과. 단, 육성 서사가 없으면 이 감정이 단발로 끝날 것이라는 자각도 동시에 존재.

## 15. Cross-Analysis Summary

### 15.1 핵심 인사이트 5선

**1. PD 역할 내면화가 애착의 근거 - U5와의 결정적 차이**

U5(최지윤)는 선택지 부족으로 "퍼즐 끼워 맞추기" 감각을 경험하며 애착 미형성. U6(김민지)는 능력치 기반 전략적 선택을 실제로 수행하여 PD 역할을 내면화했고, 그 결과 "내 아이"라는 정서적 동일시가 발생. 선택의 주체성이 애착 강도를 결정한다는 가설(H4)을 뒷받침.

**2. 초기 애착은 형성됐으나, 지속 구조가 없다**

"내 아이" 발화, 홍보 의지, 라디오 돌리기 전략 사고 등은 모두 초기 애착 형성의 신호. 그러나 경연/스탯 성장 시스템이 없으면 이 애착을 서비스가 받아줄 구조가 없음. H1을 부분 검증했으나, "캐스팅만으로는 충분하지 않고 육성 고리가 필요"라는 결론으로 수렴.

**3. 실력 중심 소비 성향은 서비스 전반에 일관되게 적용**

캐스팅 기준(능력치 > MBTI), 콘셉트 선택(실력/칼각 > 케미), 경연/성장 기대까지 실력 중심 판단이 일관됨. 이 유저 유형에게는 능력치 정보의 가시성과 정확성이 몰입의 핵심 변수. MBTI 중심 설계는 설득력 약함.

**4. 팬덤 지식 보유 유저의 능동적 에너지를 흡수할 기능이 없다**

라디오 돌리기 등 실제 팬덤 전략을 서비스 내 그룹에 투영하려는 의도를 보임. 그러나 현재 서비스는 이러한 팬덤 활동 기능이 없어 이 에너지가 서비스 내에서 소비되지 못함. 이 유저 유형에게는 팬덤 활동 연계 기능이 강력한 리텐션 트리거가 될 것.

**5. 직접 생성 장벽이 창작 자유도 차별화를 무력화**

직접 생성을 시도했으나 속도/완성도 문제로 이탈. 창작 욕구는 있으나 기술적 마찰 한 번에 포기. 직접 생성이 서비스의 핵심 차별화 포인트라면, UX 마찰 제거와 품질 향상이 선결 과제.

### 15.2 Sprint 1 가설 검증 총괄 (U6 단독)

| 가설 | 판정 | 조건/한계 |
|------|------|----------|
| H1 캐스팅만으로 애착 | 부분~중간 강도 검증 | "내 아이" 발화 + PD 역할 내면화로 초기 애착 형성. 단, 깊은 집착/독점 발화 없음. 육성 고리 없으면 단발로 끝날 가능성. U5보다 강하게 검증되나 완전 검증에는 미달. |
| H2 과정 > 결과 | 부분 검증 (육성 서사가 핵심) | 전략적 캐스팅 과정에 의미를 둠 (지지). 그러나 선택 자체보다 "육성 서사"가 더 핵심 동기로 확인 (약화). 과정은 의미 있으나, 그것은 육성의 시작으로서의 의미. |
