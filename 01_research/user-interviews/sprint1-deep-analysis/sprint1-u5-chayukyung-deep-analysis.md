## 2. Verbatim Extraction & Coding

분석 요약본(sprint1-u5-chayukyung.md)에서 추출 가능한 직접 발화 및 행동 기술을 코드화한다.

### VC-01 [역할 인식 - 사장/기획자]

> "사장이라고 생각했다."

- 코드: `역할인식-사장` `기획자정체성` `프로듀서관점`
- 비고: 캐스팅 행위를 경험한 뒤 자신의 역할을 직접 명명한 발화. 분석 요약본에 직접 인용으로 기재됨.

### VC-02 [전략적 캐스팅 - 능력치 기반 조합]

> (분석 요약 기술) 능력치 살펴보고 부족한 부분 메꾸기 / 더 좋은 조합 만들고 싶다 / 멤버 조합 자체를 즐긴다고 명시

- 코드: `전략적캐스팅` `능력치참조` `조합최적화` `과정몰입`
- 비고: 직접 발화가 아닌 연구자 기술이나, 행동 패턴으로서 코딩 처리.

### VC-03 [UI 불편 - 선택 구조]

> (분석 요약 기술) 한 번에 한 명씩 선택 구조 / 선택 인원 가시성 부족 / 블러 리스트 상단 노출

- 코드: `UX-선택구조-불편` `UX-가시성-부족` `UX-블러-위치`
- 비고: 피실험자가 직접 지적한 UI 불편 요소 3건. 디자이너 직업 특성상 UI 인지 정확도가 높음.

### VC-04 [UI 개선 제안 - 능력치 지표화]

> (분석 요약 기술) 능력치 총합/평균 제안 / 선택 인원 표시 요청 (현재 몇 명 선택 중인지 가시화 필요)

- 코드: `UX개선제안-지표화` `UX개선제안-가시화` `디자이너-관점`
- 비고: 단순 불편 지적이 아닌 구체적 해결안까지 제시. 디자이너 배경이 발화 정밀도에 영향.

### VC-05 [결과물 공유 - 친구 단위]

> (분석 요약 기술) 그룹 카드 공유 의향 있음 (친구에게 공유)

- 코드: `공유의향-친구` `사회적공유` `결과만족`
- 비고: 공유 범위가 '친구'로 한정. 불특정 다수 공유 의향과는 구별됨.

### VC-06 [캐스팅 과정의 무게감]

> (분석 요약 기술) 캐스팅 과정은 "무겁지 않았다."

- 코드: `과정-가벼움` `부담없음` `소비형-근접`
- 비고: 캐스팅을 전략적으로 접근했음에도 과정 자체를 부담스럽지 않게 인식. 경험의 양면성을 보여주는 지점.

### VC-07 [자가 인식 - 콘텐츠 소비자]

> (분석 요약 기술) 콘텐츠 소비자에 가깝다고 자가 인식

- 코드: `자가인식-소비자` `창작자정체성-약함` `H1-약화`
- 비고: 전략적 접근을 했음에도 스스로를 "소비자"로 규정. 역할 정체성의 내면화 수준이 낮음을 시사.

### VC-08 [특정 멤버 집착 없음 - 행동 관찰]

> (분석 요약 기술) 특정 멤버 집착 발화 없음

- 코드: `멤버집착-없음` `애착-미형성` `H1-2차조건-미달`
- 비고: 부재(absence)의 코딩. 전략 게임 재미에 집중하고 개별 멤버에 대한 애정 발화는 관찰되지 않음.

### VC-09 [그룹 콘셉트 - 성공 전략 사고]

> (분석 요약 기술) 프로듀서 관점 사고 / 성공 전략 사고 / 밸런스 중심 판단

> (분석 요약 기술) 데이터 없음 / 장기 기대감 발화 없음

## 3. Behavioral Sequence Analysis (행동 시퀀스 분석)

### 3.1 전체 행동 흐름 재구성

분석 요약본의 UT 구조(3.1~3.4)를 기반으로 행동 시퀀스를 재구성한다.

| 단계 | 행동 유형 | 관찰된 행동 패턴 | 비고 |
|------|-----------|------------------|------|
| 1. AI 연습생 캐스팅 | 탐색 → 전략적 선택 | 능력치 기반 조합 분석, 부족한 부분 메꾸기, UI 불편 지적 | 한 번에 한 명씩 선택 구조에 제약감 경험 |
| 2. 그룹 콘셉트 설정 | 기획 → 판단 | 프로듀서 관점 적용, 성공 전략 사고, 밸런스 중심 판단 | 일관된 전략 사고 유지 |
| 3. 결과 카드 확인 | 결과 확인 → 공유 고려 | 공유 의향 표현, 포토카드형 확장 연상, 지표화 제안 | 결과물을 공유 가능 콘텐츠로 인식 |
| 4. 이메일 입력 | (데이터 없음) | 장기 기대 발화 없음 | H3 판단 불가 |

### 3.2 핵심 행동 패턴 식별

#### 패턴 1: 전략-게임 모드

캐스팅 전 단계를 통해 차유경은 일관되게 **전략 게임 플레이어**처럼 행동한다. 능력치 확인 → 부족 포지션 파악 → 조합 최적화로 이어지는 선형 의사결정 구조를 보인다. 이는 팬이 좋아하는 멤버를 직관적으로 선택하는 패턴과 구별된다.

#### 패턴 2: 디자이너 관점의 UI 모니터링

일반 피실험자와 달리, 차유경은 캐스팅 과정에서 UX 문제를 명확하게 식별하고 개선안까지 제안한다. 이는 직업(디자이너)에서 비롯된 전문적 시각으로, 다른 피실험자의 발화와 구분하여 해석해야 한다.

#### 패턴 3: 결과물의 공유 콘텐츠화

결과 카드를 보고 즉각적으로 "친구에게 공유"와 "포토카드형 확장"을 연상한다. IP 소유보다 **공유 가능한 콘텐츠**로서의 가치를 인식하는 패턴.

### 5.2 Thinks (생각하는 것) [추론]

- [추론] "이 서비스는 전략 게임처럼 접근하면 된다." - 근거: 능력치 기반 조합 분석, 부족 포지션 파악 행동
- [추론] "내가 만든 그룹이지만, 내가 키울 것 같지는 않다." - 근거: 장기 기대 발화 없음, 자가 인식을 '소비자'로 규정
- [추론] "UI가 좀 불편하지만 그냥 쓸 수 있다." - 근거: UI 불편 지적 후에도 태스크 완주 (이탈 없음)
- [추론] "결과물은 친구에게 보여주기 좋은 콘텐츠다." - 근거: 공유 의향(친구 단위), 포토카드형 확장 언급
- [추론] "조합을 잘 만든 것 같다." - 근거: 조합 즐거움 명시, 능력치 밸런스 사고

### 5.3 Does (행동)

### 5.4 Feels (느끼는 것)

- 전략적 선택 과정에서 **집중과 몰입**

- 이메일 단계에서의 감정: **데이터 없음**

|------|------------|------|
| Says vs Feels | "사장이라고 생각했다"(역할 인식) vs 자가 인식 '콘텐츠 소비자' | 인지적 역할 부여는 되었으나 감정적 동일시는 일어나지 않음 |
| Says vs Thinks | "캐스팅 과정이 무겁지 않았다" vs [추론] 전략적 몰입 상태 | 몰입 수준과 체감 부담감이 비례하지 않음. 전략 게임은 '재미있지만 무겁지 않은' 경험 |
| Does vs Feels | 능력치 분석, 조합 최적화 등 능동적 행동 수행 vs 특정 멤버 집착 없음 | 행동의 목표가 '최적 조합 완성'이지 '특정 멤버와의 관계 형성'이 아님 |

## 6. Thematic Analysis (Braun & Clarke 6단계)

### 6.1 1단계: 데이터 숙지

분석 요약본 전체를 기반으로, U5 차유경의 경험을 구성하는 주요 요소를 확인한다.

- 캐스팅을 전략적 행위로 인식
- UI에 대한 디자이너적 관찰
- 결과물을 공유 콘텐츠로 인식
- 특정 멤버 집착 없음
- 자가 인식을 '소비자'로 규정
- 이메일 단계 데이터 없음

### 6.2 2단계: 초기 코드 생성

| 코드 | 발생 빈도 | 관련 발화/행동 |
|------|-----------|---------------|
| 전략적캐스팅 | 높음 | 능력치 기반 조합, 부족 포지션 파악, 성공 전략 사고 |
| UI관찰-디자이너관점 | 높음 | 3가지 UI 불편 지적, 2가지 개선 제안 |
| 공유콘텐츠인식 | 중간 | 친구 공유 의향, 포토카드 확장 연상 |
| 소비자자가인식 | 중간 | "콘텐츠 소비자에 가깝다" 기술 |
| 멤버집착없음 | 중간 | 특정 멤버 집착 발화 부재 |
| 과정가벼움 | 낮음 | "무겁지 않았다" |
| 장기기대없음 | 낮음 | 이메일 데이터 없음, 장기 서사 발화 없음 |

### 6.3 3단계: 테마 탐색

후보 테마:

1. "전략 게임으로서의 캐스팅"
2. "결과물은 공유 가능한 콘텐츠"
3. "역할 인식 vs 정서적 비개입"
4. "디자이너 관점의 UX 마찰"

### 6.4 4단계: 테마 검토

- 테마 1과 3은 상호 보완적: 전략 게임에 집중하기 때문에 정서적 비개입이 발생
- 테마 2는 테마 1의 결과물 처리 방식으로 포함 가능
- 테마 4는 별도 UX 분석 섹션으로 분리

최종 테마 구조:
- **핵심 테마 A**: 전략 게임으로서의 캐스팅 (과정 몰입 + 정서 비개입)
- **핵심 테마 B**: 결과물의 공유 콘텐츠화 (IP 소유보다 공유 가치)
- **부수 테마**: 디자이너 관점의 UX 마찰 관찰

### 6.5 5단계: 테마 명명

- **테마 A**: "전략 게임 몰입, 그러나 감정적 비착지 (Strategic Engagement without Emotional Landing)"
- **테마 B**: "캐스팅 결과물 = 공유 가능한 게임 결과 (Shareable Game Output)"
- **테마 C (부수)**: "디자이너 안경 효과 (Designer's Eye for UX Friction)"

### 6.6 6단계: 분석 보고서 작성

**테마 A**: 차유경은 캐스팅 과정에 전략적으로 몰입하지만, 이 몰입이 감정적 애착으로 착지하지 않는다. "사장이라고 생각했다"는 역할 인식은 존재하지만, 그것이 "내 멤버들이 잘됐으면 좋겠다"는 돌봄 심리나 "민희진이다"는 역할 동일시로 이어지지 않는다. 과정은 가볍고 재미있는 전략 게임이며, 그 과정이 끝나면 정서적 잔향이 약하다.

**테마 B**: 결과 카드를 보고 즉각적으로 '친구에게 공유'와 '포토카드형 확장'을 연상하는 것은, 차유경이 캐스팅 결과물을 IP 소유물이 아닌 공유 가능한 게임 결과물로 인식하고 있음을 보여준다. 이는 팬덤 문화(포토카드)와 게임 문화(결과 공유)를 동시에 참조하는 소비 방식이다.

**테마 C**: 디자이너로서 차유경은 UI 불편을 3가지 구체적으로 식별하고, 능력치 총합/평균 표시와 선택 인원 가시화라는 개선안까지 제시한다. 이는 다른 피실험자의 막연한 불편 표현과 질적으로 다른 수준의 관찰이다.

## 7. Affinity Mapping (친화도 맵)

### 7.1 클러스터 구성

**클러스터 1: 전략 사고 (Strategy Cluster)**

- 능력치 살펴보고 부족한 부분 메꾸기
- 더 좋은 조합 만들고 싶다
- 멤버 조합 자체를 즐긴다
- 프로듀서 관점 사고
- 성공 전략 사고
- 밸런스 중심 판단
- "사장이라고 생각했다."

**클러스터 2: UX 마찰 (UX Friction Cluster)**

- 한 번에 한 명씩 선택 구조 지적
- 선택 인원 가시성 부족 지적
- 블러 리스트 상단 노출 지적
- 능력치 총합/평균 제안
- 선택 인원 표시 요청

**클러스터 3: 결과 처리 (Output Handling Cluster)**

- 그룹 카드 공유 의향 (친구)
- 포토카드형 확장 가능성 언급
- 능력치 총합 등 지표화 요청

**클러스터 4: 정서적 비개입 (Emotional Detachment Cluster)**

- 특정 멤버 집착 발화 없음
- 콘텐츠 소비자에 가깝다고 자가 인식
- 장기 서사 기대 발화 없음
- 캐스팅 과정은 "무겁지 않았다."

### 7.2 클러스터 간 관계

- 전략 사고 클러스터와 정서적 비개입 클러스터는 역설적 공존 관계: 전략적 행동이 깊어질수록 감정 개입은 낮아짐.
- UX 마찰 클러스터는 전략 사고를 방해하는 요소: 차유경이 전략 최적화를 원하는데 UI가 이를 지원하지 않음.
- 결과 처리 클러스터는 정서적 비개입과 일관적: 결과물을 내 IP가 아니라 공유 콘텐츠로 처리함.

## 10. Mental Model Gap Analysis (멘탈 모델 갭 분석)

### 10.1 U5의 멘탈 모델

차유경의 멘탈 모델은 **"아이돌 기획사 시뮬레이션 게임"**에 가깝다.

- 캐스팅 = 선수 드래프트 또는 카드 조합 게임
- 그룹 콘셉트 = 팀 전략 설정
- 결과 카드 = 게임 결과 화면 (공유 가능)
- 이메일 입력 = (게임에서 흔한) 알림 구독 → 장기 기대 프레임 없음

### 10.2 서비스 설계 의도 vs U5 멘탈 모델

| 서비스 설계 의도 | U5 멘탈 모델 | 갭 |
|-----------------|-------------|-----|
| 캐스팅 = 애착 형성의 시작점 | 캐스팅 = 전략 게임의 한 라운드 | 설계 의도(애착)가 멘탈 모델에서 미작동 |
| 결과물 = 내가 만든 IP | 결과물 = 공유 가능한 게임 결과 | IP 소유감 발생 안 됨 |
| 이메일 = 기대 기반 전환 행동 | 이메일 = (데이터 없음 / 추론: 일반 알림) | H3 측정 자체 불가 |
| 선택 과정 = 의미 있는 행위 | 선택 과정 = 재미있지만 가벼운 게임 | 의미 부여 수준이 설계 의도보다 낮음 |

### 10.3 갭 원인 분석

1. **UI가 전략 게임 프레임을 강화**: 능력치 표시, 등급 분류 등은 RPG/카드게임 UI와 유사. 이로 인해 유저가 자연스럽게 게임 프레임을 채택.
2. **"키운다"는 프레이밍 부재**: U3(장쏘피) 사례에서 "키운다" 프레이밍이 애착을 강화했으나, 차유경의 세션에서 이 프레이밍이 활성화되었는지 확인 불가.
3. **개별 멤버 스토리 연결 부재**: 특정 멤버에 대한 서사가 전달되지 않아 개별 캐릭터 애착이 형성될 기회 없음.

## 11. Norman's 7 Stages of Action (노먼 7단계 행동 분석)

AI 연습생 캐스팅 태스크를 중심으로 분석한다.

### 11.1 목표 형성 (Goal)

- 목표: "좋은 조합의 그룹을 완성한다"
- 근거: 능력치 기반 조합 사고, 부족 포지션 파악 행동

### 11.2 의도 형성 (Intention)

- 의도: 능력치 밸런스가 맞는 멤버를 선택하겠다
- [추론] 단순히 외모나 좋아하는 캐릭터가 아닌, 능력치를 기준으로 의사결정 의도 형성

### 11.3 행동 계획 (Action Specification)

- 계획: 능력치 확인 → 포지션별 부족 파악 → 해당 포지션 강한 멤버 선택
- 문제: UI가 능력치 총합/평균을 제공하지 않아 계획 실행에 인지 부하 발생

### 11.4 행동 실행 (Execution)

- 실행: 한 번에 한 명씩 선택
- 마찰: 한 번에 한 명씩만 선택 가능한 구조 → 전체 조합을 보면서 선택 불가
- 마찰: 선택 인원이 가시화되지 않음 → 몇 명 선택했는지 기억에 의존해야 함
- 마찰: 블러 처리된 연습생이 상단에 노출 → 탐색 집중 방해

### 11.5 지각 (Perception)

- 지각 가능 정보: 개별 연습생 능력치, 등급
- 지각 불가 정보: 현재 선택된 인원 수, 선택된 멤버들의 능력치 총합/평균
- 결과: 전략적 판단에 필요한 총합 정보를 유저가 스스로 계산해야 함

### 11.6 해석 (Interpretation)

- 개별 멤버 능력치를 보고 "부족한 포지션 메꾸기" 해석 수행
- 블러 연습생을 "선택 불가"로 해석 → 리스트 탐색에서 제외

### 11.7 평가 (Evaluation)

- 최종 그룹 구성 완료 → "조합을 즐긴다"는 만족 표현
- 그러나 결과 화면에서 총합/지표가 없어 "내가 잘 만들었는지"를 수치로 확인 불가
- → 지표화 요청 발화로 이어짐

### 11.8 실행-평가 루프 마찰 요약

| 단계 | 마찰 유형 | 심각도 |
|------|-----------|--------|
| 행동 계획 | 총합 정보 미제공 → 인지 부하 | 중간 |
| 행동 실행 | 한 번에 한 명씩 선택 구조 | 중간 |
| 행동 실행 | 선택 인원 가시성 부족 | 중간 |
| 지각 | 블러 리스트 상단 노출 | 낮음-중간 |
| 평가 | 결과 화면에 지표 없음 | 낮음 |

## 12. Norman's 3 Levels of Design (노먼 3수준 분석)

### 12.1 본능적 수준 (Visceral)

**자극**: AI 연습생의 시각적 프로필, 능력치 UI, 결과 카드 디자인

**반응**:
- 블러 처리된 연습생이 상단에 노출되는 것에 대한 부정적 반응 → [추론] 탐색 의욕 저하
- 결과 카드: 포토카드형 확장을 연상할 만큼 긍정적인 시각적 반응
- 디자이너로서 UI의 시각적 완성도에 대한 민감도가 높음

### 12.2 행동적 수준 (Behavioral)

**사용성 평가**:
- 캐스팅 플로우: 완주 (이탈 없음) → 사용 가능 수준
- 전략적 조합 지원 기능: 부족 (총합/평균 미제공, 선택 인원 미가시화)
- 포지션 설정, 그룹 콘셉트 설정: 데이터 없으나 완주 기준으로 큰 마찰 없는 것으로 추정
- 이메일 입력: 데이터 없음

**사용성 강점**: 전체 플로우 완주, 조합 재미 경험 가능
**사용성 약점**: 전략적 의사결정 지원 기능 부족

### 12.3 반성적 수준 (Reflective)

**경험 후 자기 인식**:
- 스스로를 "콘텐츠 소비자에 가깝다"고 규정 → 이 서비스를 창작 도구보다 소비 콘텐츠로 반추
- 캐스팅 결과물을 "공유 가능한 게임 결과"로 반추
- 특정 멤버 집착 없음 → 반성적 차원에서도 강한 IP 소유감 형성 안 됨

**의미 부여 수준**: 낮음-중간. "전략 게임을 즐겼다"는 경험으로 수렴. "내가 이 그룹의 프로듀서다"라는 강한 서사 형성은 없음.

## 13. Hypothesis Validation (가설 검증)

### 13.1 H1: 유저는 캐스팅만으로도 애착을 느낀다

**검증 결과: 부분 지지 (선택 행위 인지 O / 정서적 애착 X)**

#### 지지 근거

| 근거 | 유형 |
|------|------|
| "사장이라고 생각했다." | 역할 인식 - 선택 행위를 의미 있는 행위로 인지함 |
| 전략적 조합 사고 (능력치 기반, 부족 포지션 파악) | 능동적 의사결정 행동 - 단순 클릭이 아님 |
| 멤버 조합 자체를 즐긴다고 명시 | 과정 만족 |

#### 반증 근거

| 근거 | 유형 |
|------|------|
| 특정 멤버 집착 발화 없음 | H1의 핵심 조건인 '애착' 미발화 |
| 콘텐츠 소비자에 가깝다고 자가 인식 | 역할 동일시 미형성 |
| IP 소유 욕구보다 "전략 게임 재미"에 가까움 | 애착의 방향이 멤버가 아닌 게임 행위 자체 |

#### 해석

H1은 선택 행위 인지 조건은 충족하나, **정서적 애착 조건은 미충족**이다. U3(장쏘피)가 "애착이 가는 거지"를 직접 언급하고, "얘네들이 잘 지냈으면 좋겠어"라는 돌봄 심리를 보인 것과 대조적으로, 차유경은 이에 상응하는 발화가 없다. H1의 2차 조건(정서적 애착 형성)은 **이 피실험자에게서는 작동하지 않았다**.

---

### 13.2 H2: 유저는 결과물보다 선택 과정에 의미를 둔다

**검증 결과: 부분 지지**

#### 지지 근거

| 근거 | 유형 |
|------|------|
| 능력치 기반 조합 분석, 포지션 최적화 | 과정에 적극적으로 의미 부여 |
| 멤버 조합 자체를 즐긴다고 명시 | 과정 자체의 가치 인정 |
| 그룹 콘셉트 설정에서 프로듀서 관점, 성공 전략 사고 | 과정 몰입 유지 |

#### 약화 근거

| 근거 | 유형 |
|------|------|
| 캐스팅 과정은 "무겁지 않았다." | 과정에 부여하는 의미의 무게가 크지 않음 |
| 결과물(그룹 카드) 공유 의향 있음 | 결과물 자체도 의미 있음 (결과 무관심은 아님) |

#### 해석

H2는 지지되나, 그 강도는 중간 수준이다. 과정에 의미를 두는 것은 맞지만, 그 과정이 "가볍다"는 인식이 공존한다. 결과물도 공유 콘텐츠로서 의미가 있으므로 "결과보다 과정"이라는 이분법이 차유경에게는 명확하게 성립하지 않는다. **과정과 결과 모두를 소비 경험의 일부로 처리**하는 패턴이다.

---

### 13.3 H3: 이메일 입력은 단순 알림이 아니라 기대 행동이다

**검증 결과: 판단 불충분**

#### 이유

| 이유 | 상세 |
|------|------|
| 이메일 입력 단계 데이터 없음 | 발화도, 행동 관찰도 수집되지 않음 |
| 장기 서사 기대 발화 없음 | 이메일과 무관하게 장기 기대를 나타내는 발화 자체가 없음 |
| 공유 범위가 친구 단위 | 불특정 다수를 향한 장기 관심 신호 없음 |

#### 해석

H3를 이 피실험자로 검증하는 것은 데이터 부재로 인해 불가능하다. 다만, 장기 서사 기대 발화가 전혀 없다는 점에서, 이메일 입력이 기대 행동으로 작동했을 가능성은 낮은 것으로 추정된다. **이 피실험자는 H3에 대한 반증 신호도, 지지 신호도 명확하게 제공하지 않았다.**

### 14.2 Pain/Gain 분석

#### Pain Points

| Pain | 발생 단계 | 심각도 | 근거 |
|------|-----------|--------|------|
| 선택 구조로 인한 조합 파악 어려움 | 캐스팅 | 중간 | 한 번에 한 명씩 선택 구조 지적 |
| 선택 진행 상황 불투명 | 캐스팅 | 중간 | 선택 인원 가시화 요청 |
| 블러 연습생이 탐색 흐름 방해 | 캐스팅 | 낮음 | 블러 리스트 상단 노출 지적 |
| 전략 판단에 필요한 총합 정보 부재 | 캐스팅 / 결과 확인 | 중간 | 능력치 총합/평균 제안 |

#### Gain Points

| Gain | 발생 단계 | 강도 | 근거 |
|------|-----------|------|------|
| 전략적 조합 재미 | 캐스팅 전반 | 중간 | 조합 자체를 즐긴다 명시 |
| 역할 인식 (사장/프로듀서) | 캐스팅 | 중간 | "사장이라고 생각했다" 발화 |
| 결과물 공유 의향 | 결과 카드 확인 | 중간 | 친구 공유 의향, 포토카드 연상 |
| 포토카드형 확장 가능성 연상 | 결과 카드 확인 | 낮음-중간 | 팬 문화 연결 관점 |

### 14.3 Pain/Gain 종합 해석

차유경의 Pain은 대부분 **전략적 조합 지원 부족**에서 발생한다. 이는 유저가 능동적 전략가로 행동하려는데 UI가 이를 충분히 지원하지 않는 미스매치다. Gain은 전략 게임으로서의 재미와 공유 가능한 결과물에 집중되어 있으며, 감정적 애착이나 장기 투자 의지 관련 Gain은 관찰되지 않는다.

이는 차유경이 이 서비스를 **"가볍게 즐길 수 있는 전략형 콘텐츠"**로 소비하고 있음을 명확히 보여준다.

## 15. 종합 요약 및 시사점

### 15.1 한 줄 요약

U5 차유경은 캐스팅 플로우를 전략 게임으로 소비하며 과정의 조합 재미는 경험했으나, 정서적 애착으로 착지하지 않았다. "사장이라고 생각했다"는 역할 인식과 "콘텐츠 소비자에 가깝다"는 자가 인식의 공존이 이 피실험자의 핵심 특성이다.

### 15.2 3대 핵심 발견

1. **전략 게임 프레임이 감정적 착지를 차단한다**: 차유경은 능력치 기반 조합 최적화에 집중하면서 전략 게임 모드로 진입했다. 이 모드는 과정 몰입을 가능하게 하지만, 동시에 개별 멤버와의 정서적 연결을 희석시킨다. H1 검증에서 선택 행위 인지는 되었으나 애착 형성은 되지 않은 이유가 여기에 있다.

2. **디자이너 관점은 고품질 UX 피드백을 생성하지만 일반화 주의**: 차유경의 UI 개선 제안(총합/평균 표시, 선택 인원 가시화, 블러 위치)은 정확하고 실행 가능한 수준이다. 그러나 이는 디자이너 직업 배경에서 비롯된 특수 역량이므로, 이 발화를 일반 사용자 니즈로 일반화할 때는 다른 피실험자의 유사 발화 여부를 교차 확인해야 한다.

3. **H3 검증 공백은 설계 보완 필요**: 이메일 입력 단계에서 데이터가 수집되지 않아 Sprint 1의 세 번째 가설 검증에 기여하지 못했다. 다음 라운드 UT에서는 이메일 입력 단계에서 발화를 유도하는 프로브(probe) 질문을 설계에 포함해야 한다.

### 15.3 다음 단계 권고

1. **전략형 소비자 세그먼트 설계 고려**: 차유경과 같이 팬 성향과 창작 성향을 동시에 보유하나 어느 쪽도 극단적이지 않은 유저는, 강한 IP 애착이 아닌 "재미있는 전략 경험"을 원한다. 이 세그먼트를 위한 별도의 가치 제안(전략 게임형 콘텐츠)이 필요하다.

2. **전략적 조합 지원 UI 강화**: 능력치 총합/평균 표시, 선택 인원 실시간 가시화는 차유경 단독 피드백이지만, 전략적 캐스팅 행동을 보이는 다른 피실험자(U3 등)에게도 유의미할 가능성이 높다. Sprint 2 설계에서 검토 우선순위를 높일 것을 권고.

3. **블러 연습생 리스트 위치 재검토**: 상단 노출이 탐색 흐름을 방해하는 것은 UX 원칙 상 명확한 문제다. 선택 가능한 연습생 우선 정렬을 즉시 적용할 것을 권고.

4. **"키우기" 프레이밍 검증 계획 수립**: U3(장쏘피) 사례에서 "키운다" 프레이밍이 공유/재방문 의지를 급상승시킨 것이 확인됐다. 차유경의 세션에서는 이 프레이밍이 적용되었는지 불명확하다. 다음 UT에서는 이 프레이밍을 의도적으로 도입한 조건과 도입하지 않은 조건을 비교 설계하여 효과를 정량적으로 측정할 것을 권고.
