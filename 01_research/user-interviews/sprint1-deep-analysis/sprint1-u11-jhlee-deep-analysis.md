> "저 같은 사람은 캐스팅 인원 만들다가 어려워서 머리 싸맬 듯 (우는 표현) 아니면 사람들한테 선지를 줘도 좋겠다.. 고를건지 걍 진짜 사람을 설계할건지.. 눈코입 키 등등 이렇게 사람 만들때 예시항목을 주거나 아니면 완전 주관식"

### VC-03 [외모 설정 구체적 UI 제안]
> "1번. 눈크기 이러면 항목이 뭐 눈이 쌍커풀 유무 크기, 눈매 이런거 5지선다 처럼 있고 마지막 6번에 주관식처럼 빈칸.. 이러면 사람들이 작성할 수도 있게..?"
- 코드: `UI-구체제안` `5지선다-선호` `주관식병행` `외모설정-구조화`

- 군집 D: 캐스팅 몰입 실패 관련 (잔여풀-매력저하, 캐스팅몰입-실패)
- 군집 E: 건설적 참여 관련 (피드백의지-높음, UI구체제안, 항목예시-요청)

### 6.4 4단계: 테마 검토

군집 D는 군집 A, B, C의 복합 결과로, 독립 테마로 유지. 군집 E는 긍정적 행동 패턴으로 별도 테마화.

### 6.5 5단계: 테마 정의 및 명명

| 테마 번호 | 테마명 | 핵심 내용 |
|-----------|--------|-----------|
| T1 | 등급 체계의 불직관성 | 등급 의미 미파악, A등급 집중 선호 예측 |
| T2 | 연습생 풀 접근성 장벽 | 계약완료 과다, 대안 경로 불명확, 직접 생성 미발견 |
| T3 | 직접 생성 경험 실패 | 이미지 생성 속도, 성별 오류, 온보딩 부재 |
| T4 | 캐스팅 몰입 미도달 | 선택지 부재로 인한 타협적 선택 |
| T5 | 건설적 피드백 역량 | 구체적 UI 제안, 서비스 개선 의지 |

### 6.6 6단계: 보고서 작성

상위 테마: "진입 단계 탐색 장벽의 복합 작용으로 캐스팅 몰입이 미도달"
- T1(등급 불직관) + T2(풀 접근 장벽) + T3(직접 생성 실패) → T4(캐스팅 몰입 미도달)
- T5는 서비스 개선을 위한 긍정 자원으로, U11이 서비스에 호의적임을 확인

## 7. Affinity Mapping

### 7.1 클러스터 A: 등급 시스템 UX

- "남은사람들이 X별로없구 a등급이 너무없음"

### 7.3 클러스터 C: 직접 생성 접근성

- "아 밑에서 새로 만들 수 있군" (안내 후 발견)

### 7.4 클러스터 D: UI 개선 제안

- "사람들한테 선지를 줘도 좋겠다"

## 11. Norman's 7 Stages of Action

### 11.1 목표 (Goal)

"원하는 연습생을 캐스팅해서 나만의 그룹을 완성한다."

### 11.2 실행 측 (Execution Side)

| 단계 | 내용 | 관찰 |
|------|------|------|
| 1. 목표 형성 | 마음에 드는 연습생 캐스팅 | 형성됨. "피드백러의 마음으로" 진입 |
| 2. 행동 계획 | 리스트에서 탐색 → 선택 → 그룹 구성 | 계획 수립됨 |
| 3. 행동 실행 | 리스트 탐색 시작 | 실행됨. 단, 즉시 장벽 발생 |

### 11.3 평가 측 (Evaluation Side)

| 단계 | 내용 | 관찰 |
|------|------|------|
| 4. 지각 | 등급 표시, 계약완료 상태 인지 | "등급은 뭐지", "사람이 너무많아요" |
| 5. 해석 | 등급 의미 추론 시도, 상황 파악 | "a가 잘하는거잖아..?" - 부분 해석 성공 |
| 6. 평가 | 현재 상태가 목표에 부합하는지 판단 | "남은사람들이 X별로없구" - 목표 미달 인식 |
| 7. 비교 | 목표와 현재 상태 비교 | 캐스팅 몰입 미도달 인식 → 타협적 대안 선택 |

### 11.4 걸프(Gulf) 분석

| 걸프 유형 | 내용 | 심각도 |
|-----------|------|--------|
| 실행의 걸프 (Gulf of Execution) | 직접 생성 기능의 위치를 찾지 못함. 등급 필터/정렬 기능 부재 | 높음 |
| 평가의 걸프 (Gulf of Evaluation) | 계약완료 연습생이 선택 가능 연습생과 동일하게 표시되어 상태 파악 어려움 | 높음 |

## 12. Norman's 3 Levels of Design

### 12.1 Visceral (본능적 반응)

- 첫인상에서 서비스에 대한 거부감은 없었음 (호의적 진입)
- 이미지 생성 속도 저하는 즉각적인 부정 반응 유발: "이미지 생성속도 상당히 느림"
- 계약완료 연습생 과다 노출은 선택지 빈곤 느낌 유발

### 12.2 Behavioral (행동적 반응)

- 등급 체계를 이해하지 못한 상태에서도 자발적 추론 시도: 능동적 행동 패턴
- 직접 생성 기능 발견 실패 → 잔여 연습생으로 전환: 회피적 대안 선택
- 5지선다 + 주관식 병행 UI를 직접 설계하는 수준의 건설적 행동
- 이미지 생성 실패 후 즉시 포기: 학습 비용 감수 의지 낮음

### 12.3 Reflective (반성적 반응)

- "저 같은 사람은 캐스팅 인원 만들다가 어려워서 머리 싸맬 듯": 자신을 기준으로 타 사용자 경험 예측
- "A등급만 사람들이 쓰고 싶어할 듯": 서비스 구조적 문제를 사용자 집단 차원으로 일반화
- "피드백러의 마음으로": 서비스 개선에 기여하겠다는 반성적 태도
- 구체적 UI 제안(1번. 눈크기 이러면...)은 사용자가 제품을 개선자 시각으로 바라보는 반성적 수준 도달

## 13. Hypothesis Validation (가설 검증)

### 13.1 H1: 유저는 캐스팅만으로도 애착을 느낀다

| 항목 | 내용 |
|------|------|
| 판정 | 미검증 (탐색 장벽으로 캐스팅 완료 미도달) |
| 근거 | A등급 연습생 부재, 계약완료 과다로 인해 캐스팅 몰입 단계 자체에 진입하지 못함 |
| 관련 발화 | "남은사람들이 X별로없구 a등급이 너무없음" |
| 시사점 | H1 검증을 위한 선제 조건 - 충분한 캐스팅 풀과 등급 온보딩 - 이 미충족 상태였음 |

### 13.2 H2: 유저는 결과물보다 선택 과정에 의미를 둔다

| 항목 | 내용 |
|------|------|
| 판정 | 부분 지지 (의향은 있으나 탐색 장벽으로 과정 자체 경험 미완) |
| 근거 | 5지선다 UI 제안, 항목 예시 요청 등 선택 과정을 구조화하려는 욕구 관찰 |
| 관련 발화 | "사람들한테 선지를 줘도 좋겠다.. 고를건지 걍 진짜 사람을 설계할건지" |
| 시사점 | U11은 선택 과정에 의미를 두고 싶어하나, 현재 UI가 선택 과정을 구조화하지 못해 이탈 |

### 13.3 H3: 이메일 입력은 단순 알림이 아니라 기대 행동이다

| 항목 | 내용 |
|------|------|
| 판정 | 미도달 (캐스팅 완료 전 세션 종료로 이메일 입력 단계 미진행) |
| 근거 | 세션이 탐색 장벽 단계에서 종료되어 이메일 입력 화면까지 도달하지 못함 |
| 관련 발화 | 해당 발화 없음 |
| 시사점 | H3 검증을 위해서는 H1/H2의 선제 조건(캐스팅 완료)이 충족되어야 함 |

### 13.4 종합 가설 판정

| 가설 | 판정 | 핵심 이유 |
|------|------|-----------|
| H1 | 미검증 | 캐스팅 몰입 단계 미진입 |
| H2 | 부분 지지 | 선택 과정 욕구는 있으나 UI 장벽으로 미경험 |
| H3 | 미도달 | 캐스팅 완료 전 세션 종료 |

## 14. Usability Issues & Pain/Gain Analysis

#### 14.1.1 등급 체계 온보딩 부재

#### 14.1.3 직접 생성 기능 발견성 낮음

#### 14.1.5 이미지 생성 성별 오류

- 심각도: 중간~높음
- 발화 근거: "여자 남자 선택했는데 왜 이미지 생성이 남자도 나왔다가 여자도 나왔다가.. 성별도 다시 결정해줘야 하나"
- 현상: 성별 선택이 이미지 생성 결과에 일관되게 반영되지 않음
- 영향: 시스템 신뢰 저하, 직접 생성 포기의 직접적 계기

#### 14.1.6 직접 생성 항목 예시 부재

- 현상: 자유 텍스트 입력만 제공되어 무엇을 입력해야 할지 모름
- 영향: 라이트 AI 유저의 직접 생성 진입 장벽 높음

### 14.4 수정 제안 (우선순위 순)

#### 14.4.1 계약완료 연습생 표시 개선 [P0]

현재 계약완료 연습생이 선택 가능 연습생과 동일하게 리스트에 표시되어 탐색 비용을 높이고 실망감을 유발한다. 계약완료 연습생을 필터링하거나 별도 섹션으로 분리하여 선택 가능 연습생만 우선 노출한다.

#### 14.4.2 직접 생성 기능 가시성 개선 [P0]

풀 고갈 상황에서 유일한 대안인 직접 생성 기능이 자발적으로 발견되지 않는다. 잔여 연습생이 부족하거나 계약완료 비율이 높을 때 직접 생성 기능을 상단에 강조하거나 빈 상태(empty state) 안내를 추가한다.

#### 14.4.3 등급 체계 온보딩 추가 [P1]

캐스팅 화면 진입 시 또는 등급 표시 위에 툴팁/설명을 추가하여 a-f 등급이 능력치를 의미한다는 것을 즉시 전달한다.

#### 14.4.4 이미지 생성 성별 오류 수정 [P1]

성별 선택이 이미지 생성 결과에 일관되게 반영되도록 수정한다.

#### 14.4.5 직접 생성 항목 구조화 [P2]

자유 텍스트 프롬프트 대신 외모 설정 항목(눈 크기/눈매, 코 형태, 키 등)을 5지선다 + 주관식 병행 방식으로 구조화하여 라이트 유저의 진입 장벽을 낮춘다.
