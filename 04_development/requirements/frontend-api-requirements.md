## Sprint 3/4 (구현 완료)

### 1. 멤버 목록 (Companion 조회)

| 데이터 | 타입 | 설명 |
| ------ | ---- | ---- |
| 멤버 식별자 | 텍스트 | 멤버 고유 식별자 |
| 멤버 이름 | 텍스트 | 멤버 표시 이름 |
| 멤버 프로필 사진 | 이미지 URL | 멤버 프로필 이미지 |

### 2. 채팅방 목록

사용처: 채팅방 목록 페이지

#### 2.1 필요 데이터

| 데이터 | 타입 | 설명 |
| ------ | ---- | ---- |
| 채팅방 식별자 | 텍스트 | 채팅방 고유 식별자 |
| 대상 멤버 식별자 | 텍스트 | 채팅 대상 companion ID |
| 마지막 메시지 내용 | 텍스트 | 가장 최근 메시지 내용 |
| 마지막 메시지 시간 | 날짜/시간 | 가장 최근 메시지 시각 |

### 3. 채팅 메시지

사용처: 채팅방 페이지

#### 3.1 필요 데이터

| 데이터 | 타입 | 설명 |
| ------ | ---- | ---- |
| 메시지 식별자 | 텍스트 | 메시지 고유 식별자 |
| 발신자 유형 | "user" \| "companion" | 메시지 발신자 유형 |

| 보낸 시간 | 날짜/시간 | 메시지 전송 시각 |

### 4. 피드 콘텐츠 목록

사용처: MyGroup 피드 탭, OtherGroup 피드 탭

#### 4.1 필요 데이터

| 데이터 | 타입 | 설명 |
| ------ | ---- | ---- |
| 피드 식별자 | 텍스트 | 피드 고유 식별자 |
| 그룹 식별자 | 텍스트 | 소속 AIdol 그룹 ID |

| 미디어 URL | 이미지 URL | 이미지 또는 영상 URL |

## Sprint 5

### 5. 멤버 스탯 조회

> 멤버의 현재 스탯과 등급을 확인하여
> 육성 목표와 진행 상황을 파악할 수 있다.

사용처: 멤버 프로필 스탯 탭

재사용 API: `GET /companions/{id}`

#### 5.1 필요 데이터

| 데이터      | 타입                            | 설명                 |
| ----------- | ------------------------------- | -------------------- |
| 보컬 스탯   | 숫자                            | vocal 수치 (0~200)   |
| 비주얼 스탯 | 숫자                            | visual 수치 (0~200)  |
| 매력 스탯   | 숫자                            | charm 수치 (0~200)   |
| 체력 스탯   | 숫자                            | stamina 수치 (0~200) |
| 등급        | "F" \| "D" \| "C" \| "B" \| "A" | stats 합계 기반 등급 |

기존 API 변경 요청:

| 항목            | 현재                     | Sprint 5 요구                                                    |
| --------------- | ------------------------ | ---------------------------------------------------------------- |
| stats 최대값    | 0~100                    | 0~200 (누적 상승, 감소 없음)                                     |
| grade 계산 기준 | stats 평균값             | stats 합계 (F: 0~59, D: 60~149, C: 150~299, B: 300~499, A: 500+) |
| grade enum      | "A" \| "B" \| "C" \| "F" | "F" \| "D" \| "C" \| "B" \| "A" (D 추가)                         |

### 6. 연습 크레딧 조회

> 멤버별 포토카드 생성 가능 횟수를 확인하여
> 생성 가능 여부를 사전에 파악하고 충전 여부를 결정할 수 있다.

사용처: 연습하기 메뉴, 포토카드 드로우 진입 시

#### 6.1 필요 데이터

요청 데이터:

| 데이터      | 타입        | 설명                  |
| ----------- | ----------- | --------------------- |
| 멤버 식별자 | 텍스트      | 조회 대상 멤버 ID     |
| 콘텐츠 타입 | "PHOTOCARD" | 조회 대상 콘텐츠 종류 |

응답 데이터:

| 데이터              | 타입      | 설명                                       |
| ------------------- | --------- | ------------------------------------------ |
| 무료 크레딧 잔여량  | 숫자      | 해당 멤버/타입의 무료 크레딧 잔여량 (0~3)  |
| 충전 크레딧 잔여량  | 숫자      | 사용자 단위 공유 크레딧 잔여량 (0~3)       |
| 다음 충전 가능 시각 | 날짜/시간 | 쿨다운 중이면 datetime, 그렇지 않으면 null |

#### 6.2 인수 조건

- 무료 크레딧은 멤버별, 콘텐츠 타입별 독립 관리된다
- 충전 크레딧은 사용자 단위로 관리된다 (멤버 간 공유)

### 7. 포토카드 생성

> 컨셉과 보상 모드를 선택하여 포토카드를 생성해서
> 멤버 스탯을 올리고 포토카드를 컬렉션에 추가할 수 있다.

사용처: 포토카드 드로우 화면

#### 7.1 필요 데이터

요청 데이터:

| 데이터      | 타입                                                   | 설명                            |
| ----------- | ------------------------------------------------------ | ------------------------------- |
| 멤버 식별자 | 텍스트                                                 | 포토카드 생성 대상 멤버 ID      |
| 컨셉        | "SCHOOL_LIFE" \| "FINGER_HEART" \| "DAILY" \| "RANDOM" | 선택한 포토카드 컨셉            |
| 보상 모드   | "FIXED" \| "RANDOM"                                    | 확정(+8 고정) 또는 랜덤(+2~+23) |

응답 데이터:

| 데이터           | 타입                                       | 설명                                   |
| ---------------- | ------------------------------------------ | -------------------------------------- |
| 포토카드 식별자  | 텍스트                                     | 생성된 포토카드 ID                     |
| 이미지 URL       | 이미지 URL                                 | 생성된 포토카드 이미지                 |
| 보상 등급        | "MISS" \| "NORMAL" \| "GREAT" \| "JACKPOT" | 랜덤 모드 결과 등급 (확정 모드는 null) |
| 비주얼 획득 스탯 | 숫자                                       | 이번 생성으로 획득한 비주얼 수치       |
| 매력 획득 스탯   | 숫자                                       | 이번 생성으로 획득한 매력 수치         |
| 체력 획득 스탯   | 숫자                                       | 이번 생성으로 획득한 체력 수치         |
| 총 획득 스탯     | 숫자                                       | 이번 생성에서 획득한 스탯 합계         |
| 현재 총 스탯     | 숫자                                       | 생성 후 멤버의 누적 스탯 합계          |
| Near-Miss 여부   | 참/거짓                                    | Near-Miss 연출 발동 여부               |

#### 7.2 인수 조건

- 무료 크레딧 또는 충전 크레딧이 1 이상 있어야 생성 가능
- 생성 성공 시 무료 크레딧 1회 차감 (무료 크레딧 소진 시 충전 크레딧 차감)
- 확정 모드는 비주얼 +5, 매력 +2, 체력 +1 고정 반환
- Near-Miss는 랜덤 모드 MISS 결과 시에만 true 가능하며, 세션당 최대 1회

#### 7.3 경계 조건

| 상황                                | 기대 동작                    |
| ----------------------------------- | ---------------------------- |
| 크레딧 없음 (무료 + 충전 모두 소진) | 오류 반환 (크레딧 차감 없음) |
| AI 생성 실패                        | 오류 반환 (크레딧 차감 없음) |
| F등급 멤버에게 Random 컨셉 선택     | 오류 반환                    |

### 8. 크레딧 충전

> 소진한 생성 횟수를 충전하여
> 포토카드를 계속 생성할 수 있다.

사용처: 충전 다이얼로그 ("결제하기" 클릭 시)

#### 8.1 필요 데이터

| 데이터              | 타입      | 설명                              |
| ------------------- | --------- | --------------------------------- |
| 충전 크레딧 잔여량  | 숫자      | 충전 후 사용자 단위 크레딧 잔여량 |
| 다음 충전 가능 시각 | 날짜/시간 | 24h 후 다음 충전 가능 시각        |

#### 8.2 인수 조건

- Sprint 5는 기간 한정 무료 충전이며, 1회 충전 시 크레딧 3회를 지급
- 충전 후 24h 쿨다운이 적용
- 충전 크레딧은 사용자 단위로 관리

#### 8.3 경계 조건

| 상황                | 기대 동작                           |
| ------------------- | ----------------------------------- |
| 쿨다운 중 충전 요청 | 오류 반환, 다음 충전 가능 시각 반환 |

### 9. 포토카드 컬렉션 조회

> 멤버별, 컨셉별로 수집한 포토카드를 확인하여
> 보유 컬렉션을 파악할 수 있다.

사용처: 포토카드 컬렉션 화면

#### 9.1 필요 데이터

| 데이터          | 타입                                                   | 설명                                       |
| --------------- | ------------------------------------------------------ | ------------------------------------------ |
| 포토카드 식별자 | 텍스트                                                 | 포토카드 고유 식별자                       |
| 멤버 식별자     | 텍스트                                                 | 포토카드 대상 멤버 ID                      |
| 컨셉            | "SCHOOL_LIFE" \| "FINGER_HEART" \| "DAILY" \| "RANDOM" | 포토카드 컨셉                              |
| 이미지 URL      | 이미지 URL                                             | 포토카드 이미지                            |
| 생성일시        | 날짜/시간                                              | 포토카드 생성 시각                         |
| 보상 등급       | "MISS" \| "NORMAL" \| "GREAT" \| "JACKPOT"             | 생성 시 획득한 보상 등급                   |
| 신규 여부       | 참/거짓                                                | 생성 후 24시간 이내 여부 (NEW 뱃지 표시용) |

필터: 멤버 식별자, 컨셉으로 필터링 가능

정렬: 생성일시 최신순

#### 9.2 인수 조건

- 사용자 본인의 컬렉션만 반환

### 10. 포토카드 삭제

> 원하지 않는 포토카드를 컬렉션에서 삭제하여
> 컬렉션을 원하는 카드만 남기도록 관리할 수 있다.

사용처: 컬렉션 카드 상세 화면

#### 10.1 필요 데이터

요청 데이터:

| 데이터          | 타입   | 설명               |
| --------------- | ------ | ------------------ |
| 포토카드 식별자 | 텍스트 | 삭제할 포토카드 ID |

응답 데이터: 없음

#### 10.2 인수 조건

- 포토카드 삭제 후에도 해당 생성으로 획득한 스탯은 유지된다
- 본인 소유의 포토카드만 삭제 가능하다

#### 10.3 경계 조건

| 상황                          | 기대 동작 |
| ----------------------------- | --------- |
| 존재하지 않는 포토카드 식별자 | 오류 반환 |
| 타인 소유 포토카드 삭제 시도  | 오류 반환 |

## 작성 가이드

새 화면/기능 추가 시 아래 구조로 섹션을 추가합니다.

```markdown
### N. {화면/기능명}

> {사용자 역할}로서,
> {행동}을 하고 싶다.
> 그래야 {목적}할 수 있다.

사용처: {페이지명}

#### N.1 필요 데이터
| 데이터 | 타입 | 필수 | 설명 |

#### N.2 인수 조건
- {조건}

#### N.3 경계 조건
| 상황 | 기대 동작 |
```

- **데이터명**: 한국어 (예: "잔여 크레딧"), 필드명 camelCase 금지
- **타입**: 텍스트, 숫자, 참/거짓, 날짜/시간, 이미지 URL, "A" \| "B"
- **질문**: 문서가 아닌 PR 본문에
