# AIdol 프론트엔드 API 요구사항

> 이 문서는 API Spec 작성 이전에 프론트엔드 팀이 작성합니다.
> 백엔드는 이 문서를 기반으로 API를 설계합니다.

---

## Sprint 3/4 (구현 완료)

### 1. 멤버 목록 (Companion 조회)

사용처: 채팅방 목록 페이지 (멤버 정보 표시), 채팅방 페이지 (대상 멤버 헤더)

#### 1.1 필요 데이터

| 데이터 | 타입 | 설명 |
| ------ | ---- | ---- |
| 멤버 식별자 | 텍스트 | 멤버 고유 식별자 |
| 멤버 이름 | 텍스트 | 멤버 표시 이름 |
| 멤버 프로필 사진 | 이미지 URL | 멤버 프로필 이미지 |

### 2. 채팅방 목록

사용처: 채팅방 목록 페이지

#### 2.1 필요 데이터

| 데이터 | 타입 | 설명 |
| ------ | ---- | ---- |
| 채팅방 식별자 | 텍스트 | 채팅방 고유 식별자 |
| 대상 멤버 식별자 | 텍스트 | 채팅 대상 companion ID |
| 마지막 메시지 내용 | 텍스트 | 가장 최근 메시지 내용 |
| 마지막 메시지 시간 | 날짜/시간 | 가장 최근 메시지 시각 |

### 3. 채팅 메시지

사용처: 채팅방 페이지

#### 3.1 필요 데이터

| 데이터 | 타입 | 설명 |
| ------ | ---- | ---- |
| 메시지 식별자 | 텍스트 | 메시지 고유 식별자 |
| 발신자 유형 | "user" \| "companion" | 메시지 발신자 유형 |
| 발신 멤버 식별자 | 텍스트 | 메시지를 보낸 멤버의 ID |
| 메시지 내용 | 텍스트 | 메시지 본문 |
| 보낸 시간 | 날짜/시간 | 메시지 전송 시각 |

### 4. 피드 콘텐츠 목록

사용처: MyGroup 피드 탭, OtherGroup 피드 탭

#### 4.1 필요 데이터

| 데이터 | 타입 | 설명 |
| ------ | ---- | ---- |
| 피드 식별자 | 텍스트 | 피드 고유 식별자 |
| 그룹 식별자 | 텍스트 | 소속 AIdol 그룹 ID |
| 미디어 유형 | "IMAGE" \| "VIDEO" | 콘텐츠 유형 |
| 미디어 URL | 이미지 URL | 이미지 또는 영상 URL |
| 썸네일 URL | 이미지 URL | 썸네일 이미지 URL (영상의 경우) |
| 생성일시 | 날짜/시간 | 업로드 일시 |

필터: 그룹 식별자로 필터링 가능

## Sprint 5 (작성 대기)

프론트엔드 팀이 기능 명세서 기반으로 작성 예정

## 작성 가이드

새 화면/기능 추가 시 아래 구조로 섹션을 추가합니다.

```markdown
### N. {화면/기능명}

> {사용자 역할}로서,
> {행동}을 하고 싶다.
> 그래야 {목적}할 수 있다.

사용처: {페이지명}

#### N.1 필요 데이터
| 데이터 | 타입 | 필수 | 설명 |

#### N.2 인수 조건
- {조건}

#### N.3 경계 조건
| 상황 | 기대 동작 |
```

- **데이터명**: 한국어 (예: "잔여 크레딧"), 필드명 camelCase 금지
- **타입**: 텍스트, 숫자, 참/거짓, 날짜/시간, 이미지 URL, "A" \| "B"
- **질문**: 문서가 아닌 PR 본문에
