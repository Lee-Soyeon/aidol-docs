# [ 260315 ] 제이채현 콘텐츠 프롬프트 피드백 및 4월 일정 미팅

- **일시**: 2026년 3월 15일
- **참석자**: 제이, 이채현

## TL;DR
- 캐스팅 이미지(MG샷, 거울샷) 프롬프트 결과 피드백 후, 3월 스프린트는 마무리하고 4월 콘텐츠 일정을 새로 수립하기로 결정

## 요약
- 캐스팅 이미지 프롬프트 결과물 리뷰: 얼굴 품질은 개선되었으나 얼굴 사이즈 일관성 문제 존재
- 배경색은 모노톤(흰색/회색 계열)으로 통일하되, 파스텔 톤 랜덤 배경도 검토
- MG샷은 레퍼런스 이미지 활용 시 품질 향상 확인, 거울샷도 양호한 결과
- 스프린트 일정이 빡빡했던 점 회고, 주 작업 시간 및 역할 조율 필요성 공감
- 4월 콘텐츠 후보: 보라트, 교복, 일상 / 우선순위는 보라트 + 교복
- 기획서 형식 합의: 명확한 요구사항 + 레퍼런스 이미지 + 프롬프트 예시
- 3월 일정은 기존 계획대로 마무리, 4월 일정을 선제적으로 수립하기로 결정

## 결정 사항
- 캐스팅 이미지 배경색은 모노톤(흰색/회색) 기본, 파스텔 랜덤 배경 옵션도 검토
- 얼굴 사이즈 일관성 확보를 우선 과제로 설정
- 3월 콘텐츠 스프린트는 현재 계획대로 마무리하고 추가 콘텐츠는 넣지 않기로 결정
- 4월 콘텐츠 우선순위: 보라트, 교복 (프로덕트 단)
- 일주일에 1개 콘텐츠 생성을 목표로 일정 수립
- 기획서 포맷: 명확한 요구사항 / 레퍼런스 이미지(있는 대로) / 프롬프트 예시 3가지 포함
- 제이가 테스트한 프롬프트 참고 자료도 기획서에 포함 (필수 반영 항목은 별도 표시)

## 주요 논의 내용

**캐스팅 이미지 프롬프트 피드백**
- 얼굴 품질은 이전보다 크게 개선됨
- 얼굴 사이즈가 이미지마다 달라 사용자가 일관성을 느끼지 못할 우려
- 배경색은 브랜딩이 아직 미확정이므로 색채가 있는 것보다 모노톤(흰색/회색)이 안전
- 파스텔 톤(핑크, 그린, 베이지 등) 랜덤 배경도 옵션으로 검토

**MG샷 및 거울샷 리뷰**
- 거울샷: 레퍼런스 이미지 활용으로 잘 뽑힘
- MG샷: 레퍼런스 이미지를 추가로 제공하면 품질 향상 가능
- 프로필 사진의 얼굴을 따르되, 포즈/각도는 레퍼런스 이미지를 따르는 방식이 효과적
- 간헐적으로 얼굴을 그대로 붙여넣는 문제 발생 (약 50장 중 1회)

**스프린트 일정 및 작업량 조율**
- 이번 스프린트에서 2개 콘텐츠 동시 진행이 빡빡했음
- 채현: 퇴근 후 작업, 목요일 밤까지 PR 제출 -> 금요일 반영 패턴
- 제이: 수목금은 학교로 인해 작업 어려움
- 일주일에 1개 콘텐츠가 적정 작업량으로 합의

**4월 콘텐츠 계획**
- 후보 콘텐츠: 보라트, 교복, 일상
- 우선순위: 보라트 + 교복 (프로덕트 단 필요)
- 일상은 키워드가 불명확해 프롬프트 작성 난이도 높음
- 하이라이트 콘텐츠도 4월에 추가될 가능성 있음 (유튜브 썸네일 형태)

**기획서 형식 합의**
- 콘텐츠 1개당 기획서 1개
- 구성: 명확한 요구사항 + 레퍼런스 이미지 + 프롬프트 예시
- 제이가 필수 반영 사항은 별도 표시, 채현이 적용 후 이상하면 자율 판단으로 제외 가능
- 레퍼런스 이미지는 많을수록 좋지만 있는 만큼만 제공

**기획 프로세스 관련 논의**
- 현재 기획(소연, 수지)에서 아이디에이션 단계가 부재해 스프린트가 밀리는 문제
- 미진이 급하게 아이디에이션을 직접 해서 기능 명세 2개를 올렸으나 스프린트 지연 발생
- 기획 관련 이슈는 소연/수지/미진에게 전달 필요
