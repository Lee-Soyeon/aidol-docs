## 요약

### 1. IR/프레젠테이션
- 여자 아이돌 예시도 남자와 동일하게 표지에 추가하기로 결정
- UT 참가자 전원 여성 → 남자 심사위원 고려 필요
- 르세라핌 등 여자 아이돌도 인기 있음 확인

### 2. 포토카드 UX 문제점
- **확정/랜덤 모드**: 사용자가 직관적으로 이해하기 어려움
- **무료 크레딧 개념**: 복잡함
- **연습하기 → 포토카드 생성 → 스탯 상승**: 연결고리가 부자연스러움
- **"비주얼" 스탯 용어**로 포토카드 생성 목적 명확히 하기로

### 3. UX 개선 방안 논의
- 온보딩 페이지보다 **로딩 화면에서 설명**하는 것이 효과적 (사람들이 온보딩 안 읽음)
- 툴팁 추가 검토
- 스쿨라이프 컨셉 중복 → 하나를 "아트"로 변경
- 멤버별 프로그레스 바 한 곳에서만 표시

### 4. 스프린트 계획
- **Sprint 5**: 현재 상태로 진행 (토요일 UI 검수 후 개발 시작)
- **Sprint 6**: UX 라이팅 + 플로우 개선, 프롬프트 가변 블록 정의

### 5. 콘텐츠 진행 (채현)
- 캐스팅 이미지 프롬프트 수정 PR 완료
- 콘텐츠 초안 PR 내일(일요일)까지
- 리뷰어: 제이, 제형, 미진, 소연
- 시스템 통합은 Sprint 6에서 논의

### 6. 기타
- 제형: 캐스팅 이미지 생성 에러 디버깅 중
- 제이: 디자인 시스템 전체 수정 → 은재에게 변경사항 정리 후 스프린트 중간중간 적용
- 은재: 애니메이션 적용 화면 위치 확인 필요
