# [ 260325 ] 콘텐츠 프롬프트 시스템 통합 미팅

- **일시**: 2026년 3월 25일 (화) 약 47분
- **참석자**: 미진, 채현, 제형, 재영, 은재
- **링크**: Google Meet

---

> **TL;DR**
> - 캐스팅 이미지 프롬프트 키워드 전달 방식(프론트→백엔드)과 콘텐츠 프롬프트 블록 랜덤 선택 구조를 확정하고, 스프린트 6 시스템 통합을 위한 역할을 분담함

## 요약

- 캐스팅 이미지 생성 시 사용자가 선택한 키워드(성별, 분위기 등)를 프론트에서 영어로 전달하고, 백엔드에서 키워드에 맞는 프롬프트를 키-밸류 매핑으로 조합하기로 함
- 콘텐츠 이미지(데일리/스쿨/핑거하트) 생성 시 각 프롬프트 블록(장소, 시선, 표정, 의상, 카메라 등) 내 경우의 수를 백엔드에서 랜덤으로 선택하여 조합하는 방식으로 결정
- 레퍼런스 이미지는 멤버 아이디 기반으로 DB에서 캐스팅 이미지를 조회하여 이미지 생성 모델에 전달
- 이미지 생성 모델을 gemini-3.1-flash-image-preview로 통일
- 캐스팅 이미지 및 콘텐츠 프롬프트 시스템 통합은 스프린트 6에서 진행

## 결정 사항

- 프론트에서 키워드만 전달, 백엔드에서 키-밸류 매핑으로 프롬프트 관리 (프롬프트 변경 시 백엔드에서 일괄 관리 가능)
- 레퍼런스 이미지는 멤버 아이디로 DB 조회하여 사용
- 콘텐츠 프롬프트 블록 내 경우의 수는 백엔드에서 랜덤 선택 (완전 랜덤, 단 품질에 따라 특정 옵션 제외 가능)
- 이미지 생성 모델: gemini-3.1-flash-image-preview로 통일
- UI 표현 방식(드롭다운/버튼)은 추후 결정, 현재는 키워드 확정에 집중
- 캐스팅 이미지/콘텐츠 프롬프트 시스템 통합은 스프린트 6
