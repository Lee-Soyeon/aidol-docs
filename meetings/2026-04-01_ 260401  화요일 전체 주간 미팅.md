# [ 260401 ] 화요일 전체 주간 미팅

- **일시**: 2026년 4월 1일 (화)
- **참석자**: 소연, 미진, 재영, 재혁, 채현, 제이

## TL;DR
- 스프린트 5 기능 구현 대부분 완료, API 연동 테스트 단계 진입. 스프린트 6은 리뷰 펜딩으로 3~4일 지연
- 콘텐츠 프롬프트 고도화 토요일까지 완료 목표, 포토카드 생성 기능 PR 리뷰 중
- IR 발표 자료 금요일까지 제출 필요, 소연 입원으로 영욱이 시연 및 자료 보완 담당
- 버그배시 프로세스 아사나 통합 관리로 개선, 회의 시간 일요일 오전 11시로 변경

## 요약

### 1. 스프린트 5 완료 및 API 연동
- 스프린트 5 기능 구현 대부분 완료, API 연동 테스트 직전 단계
- 재혁 리뷰 반영 수정 중, 오늘 내로 최종 수정 작업 예정
- API 명세에 맞춰 개발 완료, 실제 연동 후 오류 수정 작업 계획
- 재영 머지 후 최종 확인 및 테스트 진행 예정

### 2. 포토카드 기능 및 스프린트 6 일정
- 포토카드 생성 기능 스프린트 5에서 구현 완료, PR 리뷰 진행 중
- 스프린트 6에서 프로필 이미지 관련 기능 개발 예정
- 이미지 조회는 아이디 기반으로 우선 구현, 성능 이슈 시 변경 검토
- 스프린트 6 일정은 스프린트 5 리뷰 펜딩으로 약 일주일 지연

### 3. 가변 블록 및 캐스팅 이미지 개발
- 채현이 작성한 가변 블록/고정 블록 설계가 스프린트 6 기능 명세에 포함
- 프론트엔드-백엔드 간 데이터 전달 방식 기반으로 개발 가능 판단
- API 및 ERD 문서화가 개발 시작 전 필수, 프론트엔드 의견 수렴 예정

### 4. 콘텐츠 프롬프트 실험
- 채현이 월요일에 기획안 받아 초안 생성 후 이미지 실험 진행 중
- 초기 결과 만족스럽지 않아 추가 논문 분석과 수작업 병행 중
- 이번 주 토요일까지 PR 제출 후 검토 및 수정 작업 진행 목표
- 음성 생성 관련 기술 검토는 영욱과 별도 미팅 예정

### 5. IR 발표 준비
- 심사 서류 통과, 금요일까지 발표 자료 제출 필요
- 소연 입원으로 초기 참여 어려움, 회복 후 복귀 예정
- 영욱이 시연 담당, 제이가 자료 보완 지원
- 내일 별도 미팅에서 발표 자료 진행 상황 점검

### 6. 버그배시 프로세스 개선
- 개발자들이 슬랙에 테스트 완료 보고 후 버그배시 실시
- 아사나에 모든 버그를 한 곳에 모아 통합 관리하는 방식 도입
- 미진이 관련 링크 생성 및 배포 담당

### 7. 기술 도구 및 비용
- 미진이 Eleven Labs와 Kling을 사용해 음성/영상 테스트 진행
- Kling 영상 품질 우수하나 비용 부담 존재
- 실험 비용은 투자금 및 국가 지원 사업에서 충당 계획
- 일부 무료 크레딧으로 테스트 진행, 추가 필요 시 결제 예정

## 결정 사항
- 스프린트 6 일정은 스프린트 5 리뷰 완료 후 착수 (약 3~4일 지연)
- API 및 ERD 문서화를 스프린트 6 개발 전에 완료
- 콘텐츠 프롬프트 고도화는 토요일까지 완료 목표
- 버그배시는 아사나 통합 관리로 전환
- 4월부터 정기 회의 시간을 토요일에서 일요일 오전 11시로 변경
- IR 발표 시연은 영욱 담당, 자료 보완은 제이 지원
