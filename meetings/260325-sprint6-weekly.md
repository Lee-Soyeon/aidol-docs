> **TL;DR**
> Sprint 6 진행 현황 공유. API 문서 및 ERD 완료 후 리뷰-코드 작업 진입 예정. 펀딩 100명 대상 1천만 원 매출 목표로 기획 진행 중. 충전 정책(무료 3회/유료 3회) 확정. 콘텐츠 실험은 사전 기획 후 다음 주 진행. 백엔드 PR 최소 1명 리뷰어 승인 필수.

## 요약

### 1. 스프린트 진행 현황 및 개발 문서 관리

- 은재님이 작성한 API 요청서 기반으로 API 문서 작성 후 PR 제출 완료
- 프론트엔드 개발자들이 필드명 등 검토 중, 리뷰 후 확정 예정
- ERD 설계도 문서 반영 완료, 확정 시 코드 작업 시작 계획
- 소연님이 백엔드 개발자들끼리 리뷰 후 머지 진행 허용 방침 전달 예정
- 은재님이 기능명세서 기반 API 요구사항 문서 작성 완료 후 작업 분배 및 등록 진행
- 지영님은 UI 작업 우선 시작, API 확정 후 연동 작업 예정

### 2. 펀딩 기획 및 디자인

- 제이님이 현물 굿즈 펀딩 기획안 PR 올리고 디자인 일부 진행 중
- 와디즈 펀딩 기준 원가/매출 예상액 기획서 작성 완료
- 약 100명 대상, 1천만 원 매출 목표
- UI 작업 일정이 빡빡해 미진님 연장 작업 허용 검토
- 디자인 시스템 문제 정리 후 펀딩 준비 및 콘텐츠 피드백 병행 예정

### 3. 콘텐츠 기획 및 실험 계획

- 소연님이 Sprint 6 기능명세서 오늘까지 작성 예정
- 제이님이 콘텐츠 기획안 작성 후 미진님에게 전달해 프롬프트 제작 지원
- 전신/측면 콘텐츠는 실험 전 사전 기획 및 기능명세서 점검 필요
- 채현님이 실험 계획 및 기획안 작성 후 다음 주 실험 진행 제안
- 엠블럼 고도화 대신 콘텐츠 작업 우선 진행하는 방향 검토
- 실험 일정은 소연님이 최종 결정, 엠블럼은 후순위로 조정 가능

### 4. 프롬프트 및 시스템 프롬프트 관리

- 데일리/핑거/스쿨 프롬프트는 공통 베이스 시스템 프롬프트와 개별 프롬프트로 분리 관리
- 키워드 기반 구분 방식 도입해 프롬프트 옵션 및 관리 편의성 향상
- 내일까지 PR 제출 예정, 제이님이 피드백 후 수정 및 실험 재진행 계획

### 5. UI/디자인 및 애니메이션

- 피그마 댓글 중 일부 수정 요청은 다음 스프린트 반영 예정
- 이번 스프린트는 현재 UI 상태 유지, 추후 리서치 결과에 따라 변경 가능
- 카드 생성 중 로티 효과 추가 작업 범위 검토 중
- 지영님이 퍼블릭 디렉토리 작업 포함 가능, 효과음은 난이도 고려해 제외 검토
- 미스 단계 애니메이션 제외, 나머지는 구현 방향으로 결정
- CSS/JS 혼용해 흔들림 등 효과 구현 예정
- 파티클/화면 흔들림 등 축하 애니메이션은 카드 완성 부분에만 적용

### 6. 결제 및 충전 시스템

- 무료 충전: 멤버별 3회 제공
- 유료 충전: 회원 전체 계정에서 사용 가능한 총 3회 제공
- 소연님과 영웅님이 주말에 정책 방향 협의 완료
- 멤버 기반 횟수와 계정 기반 횟수를 명확히 구분해 사용자 혼란 방지 계획
- 재혁님이 계정 종속 횟수 표시 위치와 표현 방식 조율 필요성 제기

### 7. PR 리뷰 및 협업 프로세스

- 영웅님 부재로 PR 승인 위한 리뷰 권한 문제 발생
- 소연님이 권한 문제 해결 방안 확인 후 공유 예정
- 백엔드 PR: 최소 1명 리뷰어 승인 필요
- API 요청 관련 PR: 모든 리뷰어 승인 필요
- 재혁님이 백엔드 리뷰어로 지정되어 승인 절차 간소화
- 랜덤 컨셉 선택 기능은 우선 잠금 처리, 추후 기능 추가 예정
- 랜덤 클릭 시 스낵바 알림으로 안내하는 방향 구현

### 8. 기타

- 기능명세서 및 UI 작성 기간이 짧다는 지적, 디자인 스프린트 도입 초기라 조정 가능
- 프롬프트 및 디자인 작업 중복 최소화 제안
- 기능명세서와 기획안 사전 공유 강화로 작업 이중화 감소 도모
- 애니메이션 및 변경 사항은 슬랙 개발 채널에 기록해 추후 참고
